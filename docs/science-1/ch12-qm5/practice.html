Quantum theory of the hydrogen atom

18 min read · 28 practice problems

Solutions stay collapsed until you click them.

28 questions with worked answers (tap a solution to open it). These are mostly "explain" questions, since the professor wants understanding rather than derivations. Points are in brackets.

A. State and explain

Problem 1 [QM 5 · Recall · 2 pts]

Why are spherical polar coordinates used for the hydrogen atom?

Solution

Solution. Reason. The Coulomb potential U=−e2/4πε0​r depends only on r, so the system has spherical symmetry.

In spherical polar coordinates (r,θ,φ) the Schrödinger equation separates into three ordinary differential equations, one for each variable:

ψ(r,θ,φ)=R(r)Θ(θ)Φ(φ)

The boundary conditions (periodicity in φ, regularity at the poles, decay as r→∞) are also simple in these coordinates.

Problem 2 [QM 5 · Recall · 3 pts]

Explain how the three quantum numbers arise from separating the Schrödinger equation. Which condition gives each one?

Solution

Solution. Separation. Writing ψ=R(r)Θ(θ)Φ(φ) splits the equation into three. Each boundary condition produces one quantum number.

equation condition quantum number
Φ(φ) single-valued: Φ(φ+2π)=Φ(φ) ml​=0,±1,±2,…
Θ(θ) finite at the poles θ=0,π l=0,1,2,… with l≥∣ml​∣
R(r) R→0 as r→∞ (bound state) n=1,2,… with n>l, and the energies En​

Problem 3 [QM 5 · Recall · 3 pts]

Name the quantum numbers n, l and mₗ, give their allowed values, and say what physical quantity each fixes.

Solution

Solution. | number | allowed values | fixes | |---|---|---| | n (principal) | 1,2,3,… | the energy, En​=−13.6/n2 eV | | l (orbital) | 0,1,…,n−1 | the magnitude of angular momentum, L=l(l+1)​ℏ | | ml​ (magnetic) | −l,…,+l | the z-component, Lz​=ml​ℏ |

For each n there are n2 states (without spin).

Problem 4 [QM 5 · Recall · 2 pts]

How does the quantum-mechanical energy of hydrogen compare with Bohr's? What is new?

Solution

Solution. Same energies. The quantum-mechanical result is exactly Bohr's:

En​=−n213.6 eV​

What is new.

  • It comes from the wave equation, with no assumed orbits.
  • Two more quantum numbers, l and ml​, with the degeneracy n2.
  • Probability distributions instead of orbits.
  • A correct angular momentum, l(l+1)​ℏ, and selection rules for transitions.

Problem 5 [QM 5 · Recall · 2 pts]

Compare the angular momentum of hydrogen in Bohr's model and in quantum mechanics. What is surprising about s states?

Solution

Solution. | | Bohr | Quantum mechanics | |---|---|---| | magnitude | L=nℏ | L=l(l+1)​ℏ | | depends on | n | l (with l≤n−1) | | minimum | ℏ (never zero) | 0 |

Surprise. For an s state (l=0), L=0: the electron has no orbital angular momentum, which is impossible for any classical orbit. The 1s state is a spherical cloud, not a circulating electron.

Problem 6 [QM 5 · Recall · 3 pts]

What is space quantisation? Why can L never point exactly along the z-axis?

Solution

Solution. Space quantisation. The angular momentum vector can take only orientations for which

Lz​=ml​ℏ,ml​=−l,…,+l

Why L can never point along z. The largest ∣Lz​∣ is lℏ, but ∣L∣=l(l+1)​ℏ>lℏ. So Lz​<L always.

Uncertainty reason. If L pointed along z, then Lx​=Ly​=0 and Lz​=L would all be exactly known together, which the uncertainty principle forbids. Only Lz​ and ∣L∣ are definite; Lx​ and Ly​ are uncertain.

Problem 7 [QM 5 · Recall · 2 pts]

In what sense does the electron in hydrogen have no orbit? Where does Bohr's radius reappear?

Solution

Solution. No orbit. The electron has no definite path. It has only a probability density ∣ψ∣2 and can be found at any r (with different probabilities). The ground state is a spherical cloud.

Bohr's radius reappears. For the 1s state the radial probability is P(r)∝r2e−2r/a0​, which peaks at

r=a0​=0.053 nm

so a0​ is the most probable distance (the average is 23​a0​).

Problem 8 [QM 5 · Recall · 3 pts]

Why doesn't an atom in a stationary state radiate? Why does it radiate during a transition?

Solution

Solution. Stationary state. ∣Ψ∣2 is constant in time (Chapter 11), so the charge distribution does not oscillate and no radiation is emitted.

During a transition. The atom is in a superposition Ψ=aΨi​+bΨf​. The cross term makes ∣Ψ∣2 oscillate at

ν=hEi​−Ef​​

The oscillating charge distribution acts as an oscillating electric dipole, which radiates at that frequency. This explains both the frequency of the emitted light and the selection rules.

Problem 9 [QM 5 · Recall · 2 pts]

State the selection rules for allowed transitions. Why is Δl = ±1?

Solution

Solution. Selection rules (electric dipole transitions):

Δl=±1,Δml​=0, ±1

Why Δl=±1. A photon carries one unit (ℏ) of angular momentum. Angular momentum is conserved, so the atom's l must change by one unit to compensate.

Examples. 2p→1s is allowed; 2s→1s and 3d→2s are forbidden.

Problem 10 [QM 5 · Recall · 2 pts]

Why is the 2s state of hydrogen long-lived?

Solution

Solution. Reason. The only lower state is 1s, and the transition 2s→1s has Δl=0, which the selection rule Δl=±1 forbids (single-photon).

With no allowed route down, the 2s state is metastable. It decays only through much slower processes (two-photon emission, collisions) and has a lifetime of about 0.1 s, about 108 times longer than a typical allowed transition (∼10−9 s).

B. Show or work out

Problem 11 [QM 5 · Derivation · 3 pts]

Show that there are n² states with principal quantum number n.

Solution

Solution. Count. For each l=0,1,…,n−1 there are 2l+1 values of ml​:

l=0∑n−1​(2l+1)=2⋅2n(n−1)​+n=n2​

(Including spin doubles this to 2n2, the capacity of each shell.)

Problem 12 [QM 5 · Derivation · 3 pts]

List all (n, l, mₗ) states for n = 3 and write their spectroscopic names.

Solution

Solution. For n=3: l=0,1,2.

l name ml​ values states
0 3s 0 1
1 3p −1,0,1 3
2 3d −2,−1,0,1,2 5

Total =9=n2 ✓. In hydrogen they all have the same energy, −1.51 eV.

Problem 13 [QM 5 · Derivation · 4 pts]

For l = 2, find L and the possible angles between L and the z-axis.

Solution

Solution. Magnitude. L=l(l+1)​ℏ:

L=6​ℏ≈2.45ℏ

Z-component. Lz​=ml​ℏ with ml​=0,±1,±2. The angle satisfies

cosθ=6​ml​​
θ≈35∘, 66∘, 90∘, 114∘, 145∘

Check. Lz​ can never equal L: Lzmax​=2ℏ<2.45ℏ, so L is never aligned with the z-axis.

Problem 14 [QM 5 · Derivation · 4 pts]

For the 1s state, P(r) ∝ r²e^(−2r/a₀). Show that the most probable radius is a₀.

Solution

Solution. Radial probability density for 1s:

P(r)∝r2e−2r/a0​

Maximise.

drdP​∝(2r−a0​2r2​)e−2r/a0​=2r(1−a0​r​)e−2r/a0​=0

r=0 is a minimum (P=0), so the maximum is at

r=a0​​

Note. This is the most probable radius, not the average radius: ⟨r⟩=23​a0​, because of the long tail.

Problem 15 [QM 5 · Derivation · 3 pts]

Which of these transitions are allowed: 3p → 1s, 3d → 2s, 4f → 3d, 2s → 1s, 3s → 2p?

Solution

Solution. Selection rule. Δl=±1 (and Δml​=0,±1): a photon carries one unit of angular momentum.

transition Δl allowed?
3p→1s 1→0=−1 yes
3d→2s 2→0=−2 no
4f→3d 3→2=−1 yes
2s→1s 0→0=0 no
3s→2p 0→1=+1 yes

Note. 2s→1s is single-photon forbidden, which is why the 2s state is metastable.

Problem 16 [QM 5 · Derivation · 3 pts]

Explain, using a superposition Ψ = aΨᵢ + bΨ_f, why the emitted frequency is (Eᵢ − E_f)/h.

Solution

Solution. Superposition. Ψ=aΨi​+bΨf​ with Ψk​=ψk​e−iEk​t/ℏ.

Probability density.

∣Ψ∣2=∣a∣2∣ψi​∣2+∣b∣2∣ψf​∣2+ab∗ψi​ψf∗​e−i(Ei​−Ef​)t/ℏ+c.c.

The first two terms are constant in time. The cross term oscillates at angular frequency

ω=ℏEi​−Ef​​

Consequence. The charge distribution (and so the electric dipole) oscillates at this frequency, and an oscillating dipole radiates at the same frequency:

ν=hEi​−Ef​​​

A pure stationary state has a constant ∣Ψ∣2 and does not radiate.

Problem 17 [QM 5 · Derivation · 3 pts]

Sketch the radial probability densities of 1s, 2s and 2p and mark their nodes.

Solution

Solution. Radial density P(r)=r2∣Rnl​(r)∣2. The number of radial nodes is n−l−1.

state radial nodes shape of P(r)
1s 0 a single peak at a0​
2s 2−0−1=1 small inner peak, a node at 2a0​, then a larger outer peak near 5a0​
2p 2−1−1=0 a single peak at 4a0​

Observation. 2s and 2p have the same energy, but 2s has some probability close to the nucleus (penetration), which is why in multi-electron atoms 2s is lower than 2p.

C. Short numericals

Problem 18 [QM 5 · Numerical · 2 pts]

Find the energy of a 3d electron in hydrogen. Does it differ from a 3s electron? Why?

Solution

Solution. Idea. In hydrogen, En​=−13.6/n2 eV depends only on n.

E3​=−913.6​≈−1.51 eV​

The 3s, 3p and 3d states all have this energy: they are degenerate. This is special to the 1/r potential. (In atoms with more electrons, l also affects the energy.)

Problem 19 [QM 5 · Numerical · 3 pts]

For a 1s electron, the probability of being found inside r = a₀ is 1 − 5e⁻². Evaluate it (e² ≈ 7.39) and comment.

Solution

Solution. Idea. The probability of being inside a0​ is 1−5e−2, so evaluate it.

5e−2≈7.395​≈0.68 ⇒ P≈1−0.68=0.32​

Comment. The electron is more likely to be found outside a0​ than inside it, even though a0​ is the single most probable radius. The radial distribution P(r)∝r2e−2r/a0​ peaks at a0​ but has a long tail beyond it.

Problem 20 [QM 5 · Numerical · 2 pts]

A hydrogen atom is in a 4f state. Which states can it decay to directly?

Solution

Solution. Idea. Selection rule Δl=±1 (a photon carries one unit of angular momentum), and the atom must go to a lower energy.

4f has l=3, so the final state needs l=2 or 4. l=4 does not exist for n≤4, and 4d is at the same energy (no photon). So the only direct decay is

4f→3d​

D. Discuss

Problem 21 [QM 5 · Discussion · 3 pts]

Explain why the shapes of p orbitals matter for chemistry.

Solution

Solution. Shape. A p orbital has two lobes along one axis (px​, py​, pz​) with a node at the nucleus: it is directional, unlike the spherical s orbital.

Why it matters in chemistry. Bonds form where orbital lobes on neighbouring atoms overlap. So the lobe directions set the directions of bonds and therefore the shapes of molecules: the roughly 90∘ H–O–H and H–N–H angles come from p orbitals, and hybrid orbitals (sp3 tetrahedral for methane) are mixtures of s and p lobes.

Problem 22 [QM 5 · Discussion · 3 pts]

What does the hydrogen solution keep from the Bohr model and what does it discard?

Solution

Solution. Kept from Bohr.

  • The energies En​=−13.6/n2 eV.
  • The radius a0​, now as the most probable 1s radius.
  • The idea of discrete states and transitions hν=Ei​−Ef​.

Discarded.

  • Definite orbits, replaced by probability densities.
  • L=nℏ, replaced by L=l(l+1)​ℏ (and L=0 is allowed).

Added. The quantum numbers l and ml​, degeneracy n2, space quantisation, selection rules, and correct radial and angular shapes.

D. More practice: counting states and transitions

Problem 23 [QM 5 · Numerical · 3 pts]

List the orbital states of hydrogen with n=3 and give the degeneracy, with and without spin.

Solution

Solution. For n=3, l=0,1,2 and ml​=−l,…,+l:

l subshell number of ml​ values
0 3s 1
1 3p 3
2 3d 5
total=1+3+5=n2=9​ (orbital),2n2=18​ (with spin)

All 9 share the energy E3​=−13.6/9=−1.51 eV, which is a special feature of the Coulomb potential (in most other potentials the energy also depends on l).

Problem 24 [QM 5 · Numerical · 3 pts]

Find the wavelength of the photon emitted in the transition n=3→n=2 in hydrogen. Which spectral series is it?

Solution

Solution. Idea. ΔE=13.6 eV(nf2​1​−ni2​1​) and λ=hc/ΔE with hc=1240 eV nm.

ΔE=13.6(41​−91​)=13.6×365​=1.89 eV
λ=1.891240​=656 nm​

Series. Final level n=2 is the Balmer series, and this is its first line (Hα​), a red line in the visible.

Problem 25 [QM 5 · Numerical · 3 pts]

An electron is in a state with l=2. Find ∣L∣, the possible values of Lz​, and the smallest angle between L and the z-axis.

Solution

Solution. ∣L∣=l(l+1)​ℏ=6​ℏ=2.45ℏ​

Lz​=ml​ℏ,ml​∈{−2,−1,0,1,2} ⇒ Lz​=0, ±ℏ, ±2ℏ​

Smallest angle (ml​=2):

cosθ=∣L∣Lz​​=6​2​=0.816 ⇒ θ=35.3∘​

Meaning. L can never point exactly along z, because ∣Lz​∣<∣L∣ always; this is the uncertainty principle at work (knowing Lz​ exactly means Lx​ and Ly​ are undefined).

Problem 26 [QM 5 · Concept · 3 pts]

How many radial nodes and angular nodes do the 3s, 3p, 3d and 4f orbitals have?

Solution

Solution. Rules. Radial nodes =n−l−1, angular nodes =l, total nodes =n−1.

orbital n l radial nodes angular nodes total
3s 3 0 2 0 2
3p 3 1 1 1 2
3d 3 2 0 2 2
4f 4 3 0 3 3

Pattern. For fixed n the total number of nodes is the same; the orbital with the biggest l has the fewest radial nodes.

Problem 27 [QM 5 · Derivation · 4 pts]

For the hydrogen ground state ∣ψ100​∣2∝e−2r/a0​, show that the most probable distance of the electron from the nucleus is a0​.

Solution

Solution. Radial probability density. Include the spherical shell volume 4πr2dr:

P(r)=4πr2∣ψ∣2=a03​4​r2e−2r/a0​

Maximise:

drdP​∝(2r−a0​2r2​)e−2r/a0​=0 ⇒ r=a0​​

Common mistake. The wavefunction itself is largest at r=0, but the radial probability peaks at a0​, because the volume of the shell goes to zero as r→0. The average is larger still: ⟨r⟩=23​a0​.

Problem 28 [QM 5 · Concept · 3 pts]

The electric-dipole selection rule for hydrogen is Δl=±1 (and Δml​=0,±1). Which of these transitions are allowed: 3p→1s, 3d→2s, 2s→1s, 3d→2p?

Solution

Solution. Check Δl for each:

transition Δl allowed?
3p→1s 1→0: −1 ✓ allowed
3d→2s 2→0: −2 ✗ forbidden
2s→1s 0→0: 0 ✗ forbidden
3d→2p 2→1: −1 ✓ allowed

Why Δl=±1. A photon carries one unit of angular momentum, so the atom's l must change by one.

Consequence. The 2s state cannot decay to 1s by emitting a single photon, so it is long-lived (metastable, about 0.12 s) compared with 2p (about 1.6 ns).
