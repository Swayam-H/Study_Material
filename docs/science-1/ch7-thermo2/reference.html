Free energy and phases

4 min read

The course material section by section, in the order of the textbook, with the key formulas.

Third law (Atkins 3C)

  • Perfect crystal at T = 0: S = 0 (W = 1). Nernst heat theorem: ΔS → 0 as T → 0.
  • Calorimetric entropy: S(T) = S(0) + ∫C_p/T dT + Δ_fusH/T_f + ∫C_p/T dT + Δ_vapH/T_b + …
  • Debye extrapolation at low T: C_p = aT³, so S(T) = C_p(T)/3.
  • Δ_rS° = ΣνS°_m(products) − ΣνS°_m(reactants). Gas consumed gives ΔS < 0.

Helmholtz and Gibbs energies (3D)

A=U−TS,G=H−TS=A+pV
  • From Clausius dS ≥ dq/T: at constant T, V, dA ≤ 0; at constant T, p, dG ≤ 0. Equilibrium at the minimum.
  • ΔG = ΔH − TΔS. Signs: ΔH < 0, ΔS > 0 always spontaneous; ΔH > 0, ΔS < 0 never; otherwise depends on T (entropy wins at high T).
  • ΔA = maximum total work; ΔG = maximum non-expansion work (electrical, etc.).
  • Δ_rG° = ΣνΔ_fG°(products) − ΣνΔ_fG°(reactants), or Δ_rH° − TΔ_rS°. Δ_fG° = 0 for elements in reference states.

Fundamental equation and Maxwell relations (3E)

dU=TdS−pdV,dH=TdS+Vdp,dA=−SdT−pdV,dG=−SdT+Vdp
From Maxwell relation
dU (∂T/∂V)_S = −(∂p/∂S)_V
dH (∂T/∂p)_S = (∂V/∂S)_p
dA (∂p/∂T)_V = (∂S/∂V)_T
dG (∂V/∂T)_p = −(∂S/∂p)_T
  • Memory aid: each comes from equating mixed second derivatives of an exact differential.
  • Thermodynamic equation of state: π_T = (∂U/∂V)_T = T(∂p/∂T)_V − p. Perfect gas 0; van der Waals a/V_m².
  • (∂G/∂T)_p = −S; (∂G/∂p)_T = V.
  • Gibbs–Helmholtz: (∂(G/T)/∂T)_p = −H/T².
  • Pressure dependence: condensed phase ΔG ≈ V_mΔp; perfect gas G_m(p) = G_m° + RT ln(p/p°).

Phase diagrams (4A)

  • Chemical potential of a pure substance μ = G_m. Stable phase = lowest μ; coexistence where μ is equal.
  • Transferring dn from a region of μ₁ to μ₂ changes G by (μ₂ − μ₁)dn; matter flows to lower μ.
  • Areas: one phase. Lines: two phases. Triple point: three. Critical point: end of the liquid–vapour line.
  • Water: triple point 273.16 K, 611 Pa; solid–liquid line has negative slope (ice less dense). CO₂: triple point 5.11 atm, so it sublimes at 1 atm.
  • Phase rule: F = C − P + 2. For C = 1: P = 1 area (F = 2), P = 2 line (F = 1), P = 3 point (F = 0). Maximum phases in equilibrium: C + 2.

Phase transitions (4B)

  • (∂μ/∂T)_p = −S_m (falls faster for gas, then liquid, then solid); (∂μ/∂p)_T = V_m.
  • Clapeyron: dp/dT = Δ_trsH/(TΔ_trsV). Solid–liquid: steep, slope sign set by ΔV.
  • Clausius–Clapeyron (vapour ideal, V_liquid neglected):
dTdlnp​=RT2Δvap​H​,lnp1​p2​​=−RΔvap​H​(T2​1​−T1​1​)
  • ln p vs 1/T has slope −Δ_vapH/R. With log₁₀, multiply the slope by 2.303.
  • Trouton's rule: Δ_vapS ≈ 85 J K⁻¹ mol⁻¹ for many liquids.

What to be able to do without notes

  • State the third law and use S = C_p/3 at low T and tabulated S° for Δ_rS°.
  • Derive the criteria dA ≤ 0 and dG ≤ 0 from the Clausius inequality.
  • Calculate Δ_rG° and say when a reaction becomes spontaneous.
  • Write dU, dH, dA, dG and derive any Maxwell relation; use one to find π_T or (∂S/∂V)_T.
  • Read a phase diagram and apply F = C − P + 2.
  • Derive the Clapeyron equation and use Clausius–Clapeyron for Δ_vapH or a boiling point.
