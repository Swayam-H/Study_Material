Master theorem

T(n)=aT(n/b)+O(nd): O(nd) if d>logb​a; O(ndlogn) if d=logb​a; O(nlogb​a) if d<logb​a. Otherwise sum the recursion tree level by level.

FFT in five lines

  • A(x)=Ae​(x2)+xAo​(x2); ω=e2πi/n, ωn/2=−1, ω2 is a primitive (n/2)th root.
  • rj​=sj​+ωjsj′​, rj+n/2​=sj​−ωjsj′​.
  • Mn​(ω)−1=n1​Mn​(ω−1), because ∑ℓ​ωℓd=0 for d≡0.
  • Multiply: pad to n≥2d+1 (power of 2), FFT both, multiply pointwise, inverse FFT.
  • n=8: ω=2​1+i​, ω2=i, ω3=2​−1+i​, ω4=−1.

Graph facts

  • Cycle in a directed graph ⟺ DFS back edge. DAG: decreasing post order is topological.
  • Dijkstra proof: the first edge of a shortest path leaving the done set, plus w≥0.
  • Bellman–Ford: after round k, dist ≤ best path with ≤k edges.
  • Cut property: lightest edge across a cut respecting X extends X to an MST (exchange on the cycle). Distinct weights ⇒ unique MST (lightest edge in the symmetric difference).

Matching facts

  • GS: proposers only go down, receivers only go up. Terminates (≤n2), perfect, stable, proposer-optimal, receiver-pessimal.
  • Unique stable matching if men- and women-proposing agree: else (m,w) from S blocks S′.
  • Hall: matching covering L ⟺ ∣N(S)∣≥∣S∣ ∀S⊆L. Prove by double counting edges out of S. Disprove with one violator.
  • d-regular bipartite ⇒ perfect matching ⇒ union of d perfect matchings. SDR and Latin squares follow.
  • Berge: maximum ⟺ no augmenting path (via M⊕M∗: paths and even cycles).
  • König: max matching = min vertex cover (bipartite), C=(L∖Z)∪(R∩Z).

Greedy facts

  • Huffman: merge the two smallest; cost =∑fi​ℓi​ = sum of internal node weights; proof by exchange (two smallest are deepest siblings) + induction on n.
  • Kraft: ∑2−ℓi​≤1. k-ary Huffman: pad with zeros until n−1≡0(modk−1).
  • Interval scheduling: earliest finish (stays ahead). Interval partitioning: sort by start; rooms = depth.

DP answer skeleton (one mark each)

  1. Table and what an entry means, where the answer is. 2. Base cases. 3. Recurrence by the first/last decision. 4. Infeasible options: excluded from the max or −∞, never 0. 5. Fill order and backtracking with a choice table. 6. States × work; rolling arrays for value only; say "pseudo-polynomial" when a value like B appears.

Max-flow facts

  • Capacity counts only forward edges P→Q. Cut invariance: val(f)=f(P→Q)−f(Q→P).
  • Weak duality: val ≤ cut. Equality is a certificate for both.
  • Residual: forward c−f, backward f. FF stops ⇒ reachable set P∗ gives a cut with saturated out-edges and empty in-edges ⇒ MFMC.
  • Integrality: integer capacities ⇒ an integral max flow exists (not all max flows).
  • Check for a backward-edge augmenting path before stopping (CT I lost 2.5 marks for stopping at 14).
  • Reductions: matching (s→L→R→t, unit); Hall (∞ middle, finite cut ⇒ N(S)⊆T); Menger (unit capacities + decomposition); vertex capacities (split vin​→vout​); super source/sink; demands and lower bounds; project selection (∞ prerequisite edges, profit = positives − min cut); protected edges (capacity ∣E∣+1).
  • Write: construction · flow ⇒ solution (cite integrality) · solution ⇒ flow · MFMC · size and time.

Randomized facts

  • Indicators + linearity (no independence needed) + averaging ⇒ existence.
  • Random cut: Pr[edge cut]=21​ ⇒ m/2. Directed: p(1−p) ⇒ m/4. 3 colours: 32​m. 3-SAT: 87​m. Random order DAG: 21​ per edge ⇒ m/2.
  • E[bad]<1 ⇒ some outcome has no bad item.
  • Edge indicators of a random cut: pairwise independent, not mutually (triangle).
  • Sequential greedy: each vertex cuts at least half of its edges to placed neighbours ⇒ ≥m/2.
  • Fingerprint: Pa​(r)modp; nonzero degree-d polynomial over a field has ≤d roots; one-sided error; deterministic equality needs n bits (pigeonhole).
  • Rolling hash: H(i+1)=r(H(i)−s[i]R)+s[i+m], R=rm−1modp; reduce negatives mod p.
  • Palindrome: P=F−R=∑j​(sℓ−j​−sj+1​)xj; HF​←HF​r+si​, HR​←HR​+si​pow, pow←pow⋅r. Need p>k too.
  • 2D: pixel (u,j) gets x(m−1−j)m+(m−1−u), degree m2−1.

NP facts

  • To show X NP-hard: known ≤P X (from the known, to the new). Then five parts: X∈ NP (certificate, check, time) · direction · construction · both directions · polynomial size.
  • NP = poly-time verifier + poly-size certificate (completeness, soundness). P ⊆ NP. NP-hard ≠ every instance hard.
  • Decision ⇒ value by binary search (O(logm) calls) ⇒ solution by self-reducibility (n+1 calls).
  • 3-SAT → NAE-4SAT: add z to every clause (flip all if z=1). NAE-4 → NAE-3: NAE(a,b,w)∧NAE(¬w,c,d), fresh w.
  • NAE-3SAT → Max-Cut: vertices xi​,¬xi​; edge xi​¬xi​; triangle per clause; k=n+2m. A triangle has ≤ 2 cut edges, so hitting k forces every variable edge cut and every triangle split.
  • 3-SAT → IS: triangle per clause, edges between complementary literals, k=m.
  • IS ↔ VC: S independent ⟺ V∖S is a cover (k↦n−k). IS ↔ Clique: complement graph.
  • VC → Set Cover: universe = edges, Sv​ = edges at v.
  • 3-SAT → 3-Colouring: palette triangle T/F/B, literal pairs joined to B, OR-gadgets forced to T.
  • Two bracket types need Ω(n) memory deterministically (reduction from equality); the randomized checksum uses O(logn).
  • 3-XOR-SAT is in P (Gaussian elimination, XOR has inverses); 3-SAT is NP-complete; MaxCut is NP-hard, MinCut is in P.
