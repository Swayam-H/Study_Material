Polynomial multiplication and the FFT

13 min read · 5 practice problems

Solutions stay collapsed until you click them.

The Fast Fourier Transform multiplies two degree-d polynomials in O(dlogd) time instead of O(d2). It is divide and conquer, made possible by a clever choice of points to evaluate at: the complex roots of unity. The midsem gave it 4 of 30 marks (an 8-point transform by hand, plus the pseudocode), and Assignment 1 Q1 used it. Sources: Lectures 3, 4 and 8; DPV 2.6; Tutorial 1.

The problem

In short: Multiplying polynomials directly pairs every term with every term, O(d2) work. We want O(dlogd).

Given A(x)=a0​+a1​x+⋯+ad​xd and B(x)=b0​+⋯+bd​xd, find C(x)=A(x)B(x)=c0​+⋯+c2d​x2d. Each coefficient is

ck​=i=0∑k​ai​bk−i​,

which is called a convolution. Computing each ck​ directly costs Θ(d), so Θ(d2) for all of them.

Two representations

In short: A polynomial can be stored as its coefficients or as its values at enough points. Multiplying is easy with values; the hard part is converting between the two.

  • Coefficients: the list (a0​,…,ad​).
  • Values: A(x0​),…,A(xd​) at any d+1 different points.

Fact. The values at any d+1 different points pin down a degree-d polynomial completely. Reason: if two such polynomials agreed at d+1 points, their difference would have degree ≤d but d+1 roots, so it must be zero.

With values, multiplying is easy: C(xk​)=A(xk​)B(xk​) at each point, O(n) in total. Since C has degree 2d, we need n≥2d+1 points. The plan:

  1. Evaluate A and B at n points (n a power of 2, n≥2d+1).
  2. Multiply the values point by point: O(n).
  3. Interpolate: turn C's values back into coefficients.

At arbitrary points, step 1 costs O(n2) (Horner's rule takes O(n) per point). The FFT does steps 1 and 3 in O(nlogn) by picking the points cleverly.

The even/odd split

In short: Evaluating A at x and at −x shares almost all the work, because both use the same two half-size polynomials in x2.

Split A into its even and odd powers:

A(x)=Ae​(x2)+xAo​(x2).

Ae​ uses the even-index coefficients (a0​,a2​,a4​,…) and Ao​ the odd-index ones (a1​,a3​,…). Each has half the degree. Example from Lecture 3: A(x)=3+4x+6x2+2x3+x4+10x5 gives Ae​(y)=3+6y+y2 and Ao​(y)=4+2y+10y2.

Now suppose the points come in ± pairs ±x0​,…,±xn/2−1​. Since x and −x have the same square,

A(xi​)=Ae​(xi2​)+xi​Ao​(xi2​),A(−xi​)=Ae​(xi2​)−xi​Ao​(xi2​).

So all n values need only Ae​ and Ao​ at the n/2 squares xi2​: two half-size problems. To keep recursing, the squares must also come in ± pairs, and their squares too, all the way down. Real numbers can't do this, because squares of reals are never negative. The complex nth roots of unity can.

Roots of unity

In short: These are evenly spaced points on the unit circle. Squaring them gives the same kind of point set, half as large, so the split can repeat all the way down.

ω=e2πi/n=cosn2π​+isinn2π​,ωn=1.

The nth roots of unity are 1,ω,ω2,…,ωn−1, spaced evenly around the unit circle. ω is a primitive nth root, meaning ωk=1 for 0<k<n.

Three properties the FFT uses (n even):

  • They come in ± pairs: ωj+n/2=−ωj, because ωn/2=eπi=−1 (half a turn).
  • Their squares are roots of half the order: (ωj)2=(ω2)j, and ω2 is a primitive (n/2)th root of unity.
  • They sum to zero: if d≡0(modn), then ∑ℓ=0n−1​ωℓd=ωd−1ωnd−1​=0. If d≡0, the sum is n.

Values to know for n=8: ω=2​1+i​, ω2=i, ω3=2​−1+i​, ω4=−1, ω5=−ω, ω6=−i, ω7=−ω3. For n=4: 1,i,−1,−i.

The FFT algorithm

In short: Evaluate the even and odd halves at the n/2 squared points, then combine each pair with a plus and a minus (the butterfly).

A(ωj)=Ae​(ω2j)+ωjAo​(ω2j),A(ωj+n/2)=Ae​(ω2j)−ωjAo​(ω2j)​
FFT(a = (a_0, ..., a_{n-1}), ω):        // n a power of 2, ω a primitive n-th root
    if ω = 1: return a                   // n = 1
    (s_0, ..., s_{n/2-1})  ← FFT((a_0, a_2, ..., a_{n-2}), ω²)
    (s'_0, ..., s'_{n/2-1}) ← FFT((a_1, a_3, ..., a_{n-1}), ω²)
    for j = 0 to n/2 - 1:
        r_j       ← s_j + ω^j · s'_j
        r_{j+n/2} ← s_j − ω^j · s'_j
    return (r_0, ..., r_{n-1})

These four lines are exactly the four blanks in Midsem Q1.3 (0.5 marks each). The two lines inside the loop are called the butterfly. Since −ωj=ωj+n/2, writing rj+n/2​=sj​+ωj+n/2sj′​ is also accepted.

Running time. Two half-size calls plus O(n) work to combine: T(n)=2T(n/2)+O(n)=O(nlogn).

The matrix view

In short: Evaluating at all roots of unity is one matrix–vector product, and the FFT is a fast way to do that product.

Evaluating at all the roots of unity is the same as multiplying by the Fourier matrix Mn​(ω), whose entries are (Mn​)jk​=ωjk for j,k=0..n−1:

​A(1)A(ω)⋮A(ωn−1)​​=Mn​(ω)​a0​a1​⋮an−1​​​.

The vector Mn​(ω)a is called the (discrete) Fourier transform of a. The FFT computes it fast.

Interpolation: the inverse FFT

In short: Going back from values to coefficients is the same FFT run with ω−1 instead of ω, then divided by n.

Mn​(ω)−1=n1​Mn​(ω−1)​

Proof. Entry (j,k) of Mn​(ω)Mn​(ω−1) is ∑ℓ​ωjℓω−ℓk=∑ℓ​ωℓ(j−k).

  • If j=k, every term is 1, so the sum is n.
  • If j=k, then 0<∣j−k∣<n, so ωj−k=1, and the geometric sum is ωj−k−1ωn(j−k)−1​=0.

So the product is nI.

Another view (Lecture 4). The columns of Mn​ are orthogonal under the complex inner product ⟨u,v⟩=∑uℓ​vℓ​​, and each has length n​. So Mn​/n​ is unitary, and the inverse of a unitary matrix is its conjugate transpose. Since ω=ω−1, this gives the same formula.

So interpolation is the same FFT, run with ω−1, then divided by n. ω−1 is also a primitive nth root of unity, so the same code works. In Lecture 8's code, the inv flag flips the sign of the angle and divides each butterfly output by 2. Over log2​n levels that divides by n in total.

Lecture 8's picture for row m: am​=n1​∑j​A(ωj)ω−jm=n1​∑k​ak​∑j​ωj(k−m). Multiplying by ω−jm "untwists" term k=m, so its n steps all point the same way and add up to n. Every other term keeps turning, its steps go round a full loop, and they cancel to 0.

Multiplying polynomials in O(nlogn)

In short: Convert both polynomials to values, multiply the values pointwise, and convert back.

  1. Let n be the smallest power of two with n≥2d+1 (C has degree up to 2d, so up to 2d+1 coefficients). Pad a and b with zeros to length n.
  2. a^=FFT(a,ω) and b^=FFT(b,ω).
  3. c^j​=a^j​b^j​ for each j.
  4. c=n1​FFT(c^,ω−1). Round to integers if the inputs were integers.

Total O(nlogn). Why pad: n values cannot pin down a polynomial of degree n or more. Without padding the product "wraps around" (a cyclic convolution).

Integer multiplication. An n-digit integer is a polynomial evaluated at x=10. Multiply the polynomials with the FFT, then fix up the carries. This uses O(nlogn) arithmetic operations on small numbers.

A polynomial from its roots (Lecture 8, Assignment 1 Q1)

In short: Multiply the factors in a balanced tree, using FFT multiplication at every level.

Given z0​,…,zn−1​ (repeats allowed), find the coefficients of P(x)=∏i​(x−zi​). This is the polynomial that is zero exactly at the zi​, since P(zj​)=0 iff (x−zj​) divides P.

  • One factor at a time costs Θ(i) at step i, so Θ(n2) in total. The FFT doesn't help here, because one of the two operands has only two terms.
  • Balanced product tree: recursively compute L(x)=∏i<n/2​(x−zi​) and R(x)=∏i≥n/2​(x−zi​), each of degree n/2, then multiply them with the FFT in O(nlogn):
T(n)=2T(n/2)+O(nlogn)=O(nlog2n)​

Proof of the bound (recursion tree). Level j has 2j nodes. Each multiplies two polynomials of degree n/2j+1, costing O(2jn​log2jn​)≤O(2jn​logn). So each level costs O(nlogn), and log2​n levels give O(nlog2n). The basic master theorem does not apply here, because the extra term is nlogn, not nd. Add up the levels instead.

Correctness by induction: the node for indices [l,r) returns ∏i∈[l,r)​(x−zi​). So the root returns P, which has degree n and leading coefficient 1.

Practice

FF1 (DPV 2.7). What is the sum of the nth roots of unity? Their product, if n is odd?

Solution

Solution. Sum: ∑j=0n−1​ωj=ω−1ωn−1​=0 for n>1. Product: ω0+1+⋯+(n−1)=ωn(n−1)/2. For odd n, (n−1)/2 is an integer, so this is (ωn)(n−1)/2=1.

FF2 (DPV 2.8a). Compute the FFT of (1,0,0,0) and the inverse FFT of (1,0,0,0), with ω=i.

Solution

Solution. A(x)=1 is constant, so its values at 1,i,−1,−i are (1,1,1,1). Inverse: 41​M4​(ω−1)(1,0,0,0)T is 41​ times the first column, (41​,41​,41​,41​).

FF3. Use the FFT to multiply A(x)=1+x and B(x)=1+2x (show each step).

Solution

Solution. deg C = 2, so n=4 and ω=i. Pad: a=(1,1,0,0), b=(1,2,0,0). Evaluate at 1,i,−1,−i: a^=(2,1+i,0,1−i), b^=(3,1+2i,−1,1−2i). Pointwise: c^=(6,(1+i)(1+2i),0,(1−i)(1−2i))=(6,−1+3i,0,−1−3i). Inverse with ω−1=−i: ck​=41​∑j​c^j​(−i)jk. c0​=41​(6+(−1+3i)+0+(−1−3i))=1. c1​=41​(6+(−1+3i)(−i)+(−1−3i)(i))=41​(6+(i+3)+(−i+3))=3. c2​=41​(6−(−1+3i)−(−1−3i))=2. c3​=41​(6+(−1+3i)(i)+(−1−3i)(−i))=41​(6+(−i−3)+(i−3))=0. So C(x)=1+3x+2x2, which matches (1+x)(1+2x).

FF4 (DPV 2.10 style). Find the unique polynomial of degree ≤4 with p(1)=2, p(2)=1, p(3)=0, p(4)=4, p(5)=0.

Solution

Solution. Use Lagrange interpolation: p(x)=∑k​yk​∏j=k​xk​−xj​x−xj​​. The terms with y=0 vanish, leaving p(x)=2⋅(−1)(−2)(−3)(−4)(x−2)(x−3)(x−4)(x−5)​+1⋅(1)(−1)(−2)(−3)(x−1)(x−3)(x−4)(x−5)​+4⋅(3)(2)(1)(−1)(x−1)(x−2)(x−3)(x−5)​ =121​(x−2)(x−3)(x−4)(x−5)−61​(x−1)(x−3)(x−4)(x−5)−32​(x−1)(x−2)(x−3)(x−5). Check x=3 and x=5: every term has the factor (x−3)(x−5), so p=0. Expanding is optional unless asked.

FF5. Explain why the FFT recursion needs n to be a power of 2, and what to do otherwise.

Solution

Solution. Every level halves the problem and needs the point set to split into ± pairs, which needs n even at every level, all the way down to 1. If n is not a power of 2, pad the coefficient vector with zeros up to the next power of 2. This at most doubles n, so the bound O(nlogn) is unchanged.
