Formula sheet, Lectures 01 to 19

5 min read

Every number-crunching rule from the course on one page, in the same notation as the notes.

Scheduling (L05 to L07)

Turnaround and response, for one job:

Tturnaround​=Tcompletion​−Tarrival​Tresponse​=Tfirst run​−Tarrival​​

Averages are taken over all jobs. SJF/STCF minimize average turnaround; RR minimizes average response but usually has the worst turnaround.

CFS time slice and vruntime growth, where w0​=1024 is the weight of nice 0:

time_slicek​=∑i​wi​wk​​⋅sched_latencyΔvruntimek​=wk​w0​​⋅runtimek​​

A slice never drops below min_granularity (6 ms in the slides), even with many processes.

Networking (L08 and L09)

TCP timeout estimation (EWMA, update EstimatedRTT first, then DevRTT):

EstimatedRTTDevRTTTimeoutInterval​=(1−α)EstimatedRTT+αSampleRTT,α=0.125=(1−β)DevRTT+β∣SampleRTT−EstimatedRTT∣,β=0.25=EstimatedRTT+4DevRTT​​

Sending limits and throughput:

LastByteSent−LastByteAcked≤min(cwnd,rwnd)throughput≈RTTcwnd​​

Congestion control: slow start doubles cwnd every RTT until ssthresh, then +1 MSS per RTT. On a triple duplicate ACK, ssthresh = cwnd/2 and cwnd = ssthresh. On a timeout, ssthresh = cwnd/2 and cwnd = 1 MSS.

Internet checksum: add the 16-bit words with end-around carry, then take the one's complement. The receiver's sum of all words plus the checksum must be 0xFFFF.

Memory (L10 to L13)

Base and bounds:

0≤VA<bounds⇒PA=VA+base,else fault​

Segmentation: find the offset inside the segment first, then add that segment's base. For a segment that grows downward (the stack), the offset is negative:

PA=baseseg​+offset,offsetneg​=raw offset−max segment size​

Paging with a page size of 2k bytes and an n-bit virtual address:

offset bits=k,VPN bits=n−k,PA=(PFN≪k)∣offset​

Size of a linear page table:

page table size=2n−k×PTE size​

For example, 32-bit addresses with 4 KB pages and 4-byte PTEs give 220×4=4 MB per process.

Multi-level page tables: with page size P and PTE size e, one page of the table holds P/e entries, so each level indexes log2​(P/e) bits of the VPN:

levels=⌈log2​(P/e)VPN bits​⌉​

Effective access time with a TLB (lookup t, memory access m, hit rate h, single-level table):

EAT=h(t+m)+(1−h)(t+2m)​

With an L-level table, a miss costs t+(L+1)m instead of t+2m.

Average memory access time with swapping (memory TM​, disk TD​):

AMAT=TM​+Pmiss​⋅TD​​

Concurrency (L14 to L17)

A semaphore's value, when negative, is minus the number of waiting threads. Initial values for the standard uses:

Use Initial value
Lock (binary semaphore) 1
Ordering (wait for an event) 0
Bounded buffer, empty / full N / 0
Throttle to at most k threads k

Deadlock needs all four: mutual exclusion, hold and wait, no preemption, circular wait. Breaking any one prevents it, and a global lock order breaks circular wait.

File systems (L18 and L19)

Locating inode i (integer division; disks address 512-byte sectors):

blk=blockSizei×sizeof(inode)​sector=sectorSizeblk×blockSize+inodeStartAddr​​

Maximum file size with block size B, pointer size p, n=B/p pointers per indirect block, 12 direct pointers:

max size=(12+n+n2+n3)×B​

With 4 KB blocks: 48 KB direct, about 4 MB with single, 4 GB with double, 4 TB with triple indirect. xv6: (12+256)×1 KB=268 KB.

To find a byte offset's pointer: block =⌊offset/B⌋; subtract 12, then n, then n2 until it fits; in the double-indirect tree, outer slot =⌊r/n⌋, inner slot =rmodn.

I/O counts in vsfs with a cold cache:

open()≈2×depth+1create+N allocating writes=10+5N​

Each read() of a block costs 3 I/Os (inode, data, inode write for atime); a bitmap of a disk with K blocks takes K/8 bytes.
