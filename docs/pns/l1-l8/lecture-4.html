Lecture 4

Random variables as measurable functions

Deck 2, slides 1 to 8 · 8 min read · 2 practice problems

Solutions stay collapsed until you click them.

Big picture. Outcomes ω are often awkward objects: a sequence of ten die rolls, a pair of cards. What we care about is usually a number computed from the outcome: the number of sixes, the sum, the waiting time. A random variable is that number, viewed as a function X:Ω→R. It carries the probability from (Ω,F,P) over to the real line, where it becomes the induced measure PX​ (the distribution of X). The only technical condition, measurability, makes sure that "X∈B" is an event we are allowed to ask about.

Part A: the slides

Slide 1/31 and 2/31: Motivation

On the slides. Given (Ω,F,P), it is sometimes hard to work with ω directly (roll a die ten times: each ω is a sequence of numbers). We may care about functions of outcomes (the number of 6s in 10 rolls). It is convenient to work in a new, simpler space. A random variable maps (Ω,F,P) to a simpler (Ω′,F′,PX​). PX​ is the induced probability measure on Ω′.

The ten-roll example in numbers. Ω={1,…,6}10 has 610≈60 million outcomes. Let X(ω) = number of 6s in ω. Then Ω′={0,1,…,10}, just 11 values, and

PX​({k})=P({ω:X(ω)=k})=(k10​)(61​)k(65​)10−k

(Lecture 3, slide 71). We have traded a huge space for a small one without losing anything we care about.

"Random variable" is a misleading name. X is neither random nor a variable. It is a fixed, deterministic function. The randomness is in ω; X just reports a number about it.

Slide 3/31: Random variable as a measurable function

On the slide. A random variable is a function X:Ω→Ω′ that transforms (Ω,F,P) into (Ω′,F′,PX​) and is (F,F′)-measurable. X(ω)∈Ω′ for all ω. For B∈F′, the pre-image is X−1(B):={ω∈Ω:X(ω)∈B}. Measurability: for every B∈F′, X−1(B)∈F.

Pre-image, not inverse. X−1(B) is a set of outcomes, "all ω that X sends into B". It exists for every function, invertible or not. Example: two dice, X = sum, B={3}: X−1({3})={(1,2),(2,1)}.

What measurability buys. The event "X∈B" is literally the set X−1(B). If that set were not in F, P could not measure it, and "P(X∈B)" would be meaningless. Measurability guarantees that every question about X you might ask (with B∈F′) is a legitimate event.

Pre-images respect set operations (a fact used silently all the time):

X−1(Bc)=(X−1(B))c,X−1(i⋃​Bi​)=i⋃​X−1(Bi​),X−1(i⋂​Bi​)=i⋂​X−1(Bi​).

Disjoint Bi​ have disjoint pre-images (an ω cannot be sent to two places).

Slide 4/31: The induced measure

On the slide. Since X−1(B)∈F, it can be measured with P. What is PX​(B)? PX​(B):=P(X−1(B)) for all B∈F′: the induced probability measure. What if no ω has X(ω)∈B?

PX​(B)=P(X−1(B))=P({ω:X(ω)∈B})=P(X∈B)​

PX​ really is a probability measure on (Ω′,F′):

  • PX​(Ω′)=P(X−1(Ω′))=P(Ω)=1, since every ω is sent somewhere in Ω′.
  • For disjoint Bi​: PX​(⋃Bi​)=P(⋃X−1(Bi​))=∑P(X−1(Bi​))=∑PX​(Bi​), by the facts above and countable additivity of P.

The question on the slide. If no ω maps into B, then X−1(B)=∅ and PX​(B)=P(∅)=0. For example, the sum of two dice is never 13, so PX​({13})=0. That is why we can safely take Ω′=R even when X only takes a few values: the extra points get probability 0.

Slides 5/31 and 6/31: Convention, Ω′=R with the Borel σ-algebra

On the slides. Most books take Ω′=R, so F′=B(R). Recall B(R): generated by open intervals; contains [a,b], [a,b), (a,∞), [a,∞), (−∞,b], (−∞,b), {a}.

With this convention the questions we may ask about X are "is X in this Borel set?": in an interval, equal to a point, in a countable union of intervals, and so on.

A practical test for measurability. Since B(R) is generated by half-lines (Lecture 2, Part B5), it is enough to check that

{ω:X(ω)≤x}∈Ffor every x∈R.

These are exactly the events in the CDF FX​(x)=P(X≤x) (Lecture 7). For finite Ω with F=2Ω, every function is measurable, so the condition never bites in discrete problems.

An example where it bites. Ω={1,2,3}, F={∅,{1},{2,3},Ω}, and X(ω)=ω. Then {X≤2}={1,2}∈/F, so X is not a random variable on this space. The information in F cannot tell 2 from 3, so it cannot "see" X. By contrast, Y=1{ω=1} is measurable: its pre-images are ∅, {1}, {2,3} and Ω.

Slide 7/31: The picture

On the slide. Diagram: X maps Ω to R; a Borel set B pulls back to X−1(B)∈F. ΩX​R, FX​B(R), P(⋅)X​PX​(⋅). Care is needed: the events you consider in B(R) must pull back to valid events in F. X−1(B) is the pre-image or inverse image of B.

Read the picture right to left: a question about X (a set B on the real line) is translated into a question about outcomes (X−1(B)), which P answers.

Slide 8/31: The definition

On the slide. A random variable is a map X:(Ω,F,P)→(R,B(R),PX​) such that for each B∈B(R), X−1(B)={ω:X(ω)∈B}∈F and PX​(B)=P(ω∈Ω:X(ω)∈B).

X:Ω→R  with  X−1(B)∈F  ∀B∈B(R);PX​(B)=P(X−1(B))​

This is the definition last year's Quiz 1 Q3 asked for, together with the Borel σ-algebra and "all relationships between P, PX​ and FX​". A model answer:

  • P lives on (Ω,F) and measures events about outcomes.
  • PX​ lives on (R,B(R)) and is defined by PX​(B)=P(X−1(B)).
  • FX​(x)=PX​((−∞,x])=P({ω:X(ω)≤x}) is PX​ evaluated on half-lines. Because half-lines generate B(R), FX​ determines PX​ completely.
  • Discrete: pX​(x)=PX​({x}) and FX​(x)=∑u≤x​pX​(u). Continuous: FX​(x)=∫−∞x​fX​(u)du and PX​(B)=∫B​fX​(u)du.

Notation from here on. We write P(X∈B), P(X=x), P(X≤x), all shorthand for P of the pre-image. Most of the time we forget Ω altogether and work only with PX​ (Deck 2, slide 24 says exactly this).

Part B: extra worked examples

B1 (pre-images by hand). Two dice, X = sum, Y = maximum. Write out X−1({4}), Y−1({2}) and {X=4}∩{Y=2}, and find their probabilities.

Solution

Solution. X−1({4})={(1,3),(2,2),(3,1)}, probability 363​. Y−1({2})={(1,2),(2,1),(2,2)}, probability 363​. Intersection {(2,2)}, probability 361​. So P(X=4,Y=2)=361​=363​⋅363​: these events are not independent.

B2 (an induced measure on a continuous space). Pick ω uniformly from Ω=[0,1] and let X(ω)=2ω+1. Find PX​([2,2.5]) and PX​({x:x>2.9}).

Solution

Solution. X−1([2,2.5])={ω:2≤2ω+1≤2.5}=[0.5,0.75], so PX​([2,2.5])=0.25. X−1((2.9,∞))=(0.95,1], probability 0.05. In general PX​ is uniform on [1,3] with "probability = length/2". Lecture 8 does this kind of computation systematically.
