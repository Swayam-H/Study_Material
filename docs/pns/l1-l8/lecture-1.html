Lecture 1

Sample spaces, events, set theory and the axioms

Deck 1, slides 1 to 22 · 15 min read · 3 practice problems

Solutions stay collapsed until you click them.

Big picture. Probability theory needs three ingredients: a random experiment, its sample space Ω (all possible outcomes), and events (subsets of Ω). A probability measure P is a set function: it takes an event (a set) and returns a number in [0,1]. Because P acts on sets, we first need fluency with set operations. The lecture ends with a surprise: you cannot in general assign a probability to every subset of Ω. That problem is solved in Lecture 2 with σ-algebras.

Part A: the slides

Slides 1/73 to 8/73: Logistics, evaluation, outline

On the slides. Logistics; books (Bertsekas & Tsitsiklis, two by Ross; probabilitycourse.com, statlect.com, randomservices.org); evaluation (Quiz 1 15%, Midsem 30%, Quiz 2 10%, Endsem 35%, Surprise Quiz 10%); outline (probability basics, random variables, convergence and simulation, statistics, random vectors and processes); prerequisites.

Nothing examinable. Bertsekas Chapters 1 to 3 and probabilitycourse.com Chapters 1 to 4 cover the same material as these notes.

Slide 9/73: Random experiments and sample space

On the slide. A random experiment involves randomness: a coin toss, a die roll, picking a number at random from [0,1]. The sample space Ω is the set of all possible outcomes, finite or infinite: Ωc​={H,T}, Ωd​={1,…,6}, Ωu​=[0,1], Ω2c​={H,T}×{H,T}={(H,H),(H,T),(T,H),(T,T)}.

What makes a good sample space. Bertsekas (Section 1.1) asks for two things:

  • Mutually exclusive: exactly one outcome happens on each run of the experiment.
  • Collectively exhaustive: whatever happens, it is in Ω.

It must also have the right granularity: detailed enough to describe every event you care about. For "did the two tosses match?", Ω={match,no match} would do. But for "was the first toss heads?" you need Ω2c​.

Three kinds of sample space appear on this slide, and you should recognise them:

Example Size of Ω Type
coin, die, two coins finite discrete
"toss until the first head": {H,TH,TTH,…} countably infinite discrete
a number from [0,1] uncountable continuous

The type decides which tools work later. For finite or countable Ω we can give every single outcome a probability and add. For [0,1] every single point has probability 0 (slide 33), so we must work with intervals.

Ω2c​ is a Cartesian product (slide 15). Repeating an experiment n times gives Ωn, with ∣Ω∣n outcomes. Two dice: 62=36 outcomes.

Slide 10/73: Outcomes and events

On the slide. ω∈Ω is a sample point (possible outcome). A subset A⊆Ω is an event. Examples: C1​={T}; D1​={6}, D2​={1,3,5}; U1​={0.5}, U2​=[0.25,0.75]. It may not be possible to assign a probability to every subset (more later). Any guesses for P(C1​), P(D1​), P(D2​), P(U1​), P(U2​)?

Outcome vs event. An outcome is an element; an event is a set of outcomes. "The die shows 6" is the event {6}, a set with one element. We say event A occurs if the outcome ω that actually happens lies in A.

Answers to the guesses (fair coin, fair die, uniform pick):

P(C1​)=21​,P(D1​)=61​,P(D2​)=63​=21​,P(U1​)=0,P(U2​)=0.75−0.25=0.5.

The last two use the uniform rule "probability = length": [0.25,0.75] has length 0.5, while the single point {0.5} has length 0. So P(U1​)=0 even though 0.5 is a perfectly possible outcome. Slide 33 returns to this.

Slide 11/73: Probability theory

On the slide. {Random experiment, sample space, events} are the key ingredients. We measure the probability of subsets of Ω. A probability measure P is a set function: it acts on sets and measures their probability.

The key word is set function. Ordinary functions eat numbers (f(x)=x2). P eats sets: P({1,3,5})=1/2. Slide 17 defines set functions properly.

Slide 12/73: Set theory 101, operations

On the slide. Venn diagrams. Complement Ac; empty set ∅⊆A; union A∪B; intersection A∩B; difference A∖B; symmetric difference; disjoint events; identity, complement, associative, commutative, distributive and De Morgan's laws.

The blanks on the slide, filled in:

Operation Definition In words
Ac {ω∈Ω:ω∈/A} "not A"
A∪B {ω:ω∈A or ω∈B} "A or B (or both)"
A∩B {ω:ω∈A and ω∈B} "both A and B"
A∖B A∩Bc "A but not B"
AΔB (A∖B)∪(B∖A)=(A∪B)∖(A∩B) "exactly one of A,B"
disjoint A∩B=∅ "cannot both happen"

The laws.

  • Identity: A∪∅=A, A∩Ω=A.
  • Complement: A∪Ac=Ω, A∩Ac=∅, (Ac)c=A.
  • Commutative and associative: A∪B=B∪A, (A∪B)∪C=A∪(B∪C), and the same for ∩.
  • Distributive: A∩(B∪C)=(A∩B)∪(A∩C) and A∪(B∩C)=(A∪B)∩(A∪C).
  • De Morgan:
(i⋃​Ai​)c=i⋂​Aic​,(i⋂​Ai​)c=i⋃​Aic​​

This holds for any (even uncountable) collection. In words: "not (at least one)" = "none", and "not (all)" = "at least one fails".

How to prove a set identity. Show each side is a subset of the other, element by element. For De Morgan: ω∈(∪i​Ai​)c⟺ω∈/Ai​ for every i⟺ω∈Aic​ for every i⟺ω∈∩i​Aic​. □

Slide 13/73: Cardinality and countability

On the slide. ∣A∣ is the cardinality. Inclusion–exclusion: ∣A∪B∣=∣A∣+∣B∣−∣A∩B∣. Inclusion–exclusion for n sets? A is countable if it is finite or in 1-1 correspondence with N. Uncountable means not countable.

Why subtract ∣A∩B∣. Elements in both sets are counted twice by ∣A∣+∣B∣.

Three sets. Add singles, subtract pairs, add back the triple:

∣A∪B∪C∣=∣A∣+∣B∣+∣C∣−∣A∩B∣−∣A∩C∣−∣B∩C∣+∣A∩B∩C∣.

n sets (the question on the slide).

​i=1⋃n​Ai​​=i∑​∣Ai​∣−i<j∑​∣Ai​∩Aj​∣+i<j<k∑​∣Ai​∩Aj​∩Ak​∣−⋯+(−1)n+1∣A1​∩⋯∩An​∣.

Why it is right. Take an element that lies in exactly m≥1 of the sets. It is counted (1m​) times in the first sum, (2m​) in the second, and so on. Its net count is

(1m​)−(2m​)+(3m​)−⋯=1−(1−1)m=1.

So every element of the union is counted exactly once. The same formula with P instead of ∣⋅∣ is the HW on slide 32.

Slide 14/73: Monotone sequences of sets

On the slide. Increasing: A1​⊆A2​⊆…. Decreasing: A1​⊇A2​⊇…. Examples from U[0,1]: In​=[0,1−n1​], Dn​=[0,n1​].

In​ is increasing. I1​={0}, I2​=[0,21​], I3​=[0,32​], ... Each contains the previous one. Its union is

n≥1⋃​In​=[0,1).

Every x<1 is in some In​ (pick n>1−x1​), but 1 is in none of them. So the limit is the half-open interval [0,1), not [0,1].

Dn​ is decreasing. D1​=[0,1]⊇D2​=[0,21​]⊇… Its intersection is

n≥1⋂​Dn​={0}.

0 is in every Dn​, while any x>0 drops out once n1​<x.

These examples come back in Lecture 3 (continuity of P): P(In​)=1−n1​→1=P([0,1)) and P(Dn​)=n1​→0=P({0}).

Slide 15/73: Cartesian product

On the slide. A×B={(a,b):a∈A,b∈B}. If A={1,3,5} and B={2,4,6}, what is A×B? [0,1]×[0,1] is the unit square.

A×B={(1,2),(1,4),(1,6),(3,2),(3,4),(3,6),(5,2),(5,4),(5,6)},∣A×B∣=∣A∣⋅∣B∣=9.

Order matters: (1,2)∈A×B but (2,1)∈/A×B. In general ∣A1​×⋯×Ak​∣=∣A1​∣⋯∣Ak​∣. This is the multiplication principle of counting (slide 57).

Why it matters. Picking two independent uniform numbers from [0,1] is one uniform point in the unit square, and probabilities become areas. Last year's Tutorial 1 Q3 (two friends meet) is solved this way in Lecture 3 (counting, Part B9).

Slide 16/73: Power sets

On the slide. P(A) is the set of all subsets of A (and P is different from P!). What are P(Ωc​), P(Ωd​), P(Ωu​) and their cardinalities? For discrete Ω the power set is often written 2Ω.

  • P(Ωc​)={∅,{H},{T},{H,T}}, which has 4=22 elements.
  • P(Ωd​) has 26=64 elements. Each subset is decided by six yes/no choices ("is face i in it?").
  • P(Ωu​)=P([0,1]) is uncountable, and even "bigger" than [0,1] itself (Cantor's theorem: ∣P(A)∣>∣A∣ for every set).

Slide 17/73: Functions and set functions

On the slide. A function maps elements of a domain D to a range R: f:D→R. Read about injections, surjections, bijections. Set functions act on sets, so their domain is a collection of sets. Example: length l:D→R+​, D={[a,b]:a≤b}, l([c,d])=d−c.

Length is the model for P on [0,1]. Length is a set function, and it already behaves like a probability:

  • it is non-negative;
  • it adds over disjoint pieces: l([0,0.3])+l((0.3,1])=1=l([0,1]);
  • a point has length 0.

The uniform distribution on [0,1] is "probability = length". The rest of the lecture asks which sets we can measure this way.

Slide 18/73: Back to P

On the slide. Why the detour? P acts on sets. Given P(A) and P(B), can we deduce P(A∪B) or P(A∖B)? How does P act on A∪B, A∖B, A×B?

The honest answer: not from P(A) and P(B) alone. You also need P(A∩B):

P(A∪B)=P(A)+P(B)−P(A∩B),P(A∖B)=P(A)−P(A∩B).

For A×B you need to know how the two experiments are linked. If they are independent (L3), P(A×B)=P(A)P(B). These rules are all consequences of the three axioms on the next slide (proved under slide 32).

Slide 19/73: The axioms

On the slide. Axiom 1: P(∅)=0, P(Ω)=1. Axiom 2: 0≤P(A)≤1 for A⊆Ω. Axiom 3 (countable additivity): for disjoint A1​,A2​,…, P(⋃i=1∞​Ai​)=∑i=1∞​P(Ai​). What is the domain of P? Ω? P(Ω) seems like a great choice!

Domain question. Not Ω: P eats events (sets of outcomes), not outcomes. So the natural guess is the collection of all subsets, P(Ω). Slides 20 to 22 show why that guess fails when Ω is uncountable.

Reading Axiom 3. "Disjoint" means pairwise disjoint: Ai​∩Aj​=∅ for i=j. Finite additivity is a special case: take An+1​=An+2​=⋯=∅. Since P(∅)=0, the tail adds nothing, so

P(A1​∪⋯∪An​)=P(A1​)+⋯+P(An​)for disjoint Ai​.

The discrete case in one line. If Ω={ω1​,ω2​,…} is countable, every event is a countable disjoint union of single outcomes, so Axiom 3 gives

P(A)=ωi​∈A∑​P({ωi​}).

So a model is fully described by the numbers pi​=P({ωi​})≥0 with ∑i​pi​=1. With n equally likely outcomes this is the discrete uniform law P(A)=∣A∣/n, the basis of all counting problems in L3.

Slide 20/73: Towards a formal definition

On the slide. Define P:P(Ω)→[0,1] satisfying the three axioms. Is there a perceivable problem? The counter-example constructs a set function for which you cannot assign valid probabilities to every subset without violating the axioms.

Slides 21/73 and 22/73: The counter-example, and the way out

On the slides. Pick a number uniformly from the real line, so Ω=R and P(R)=1. Sets of equal length should have equal probability. R=⋃n=−∞∞​[n,n+1). If P([n,n+1))=x for all n, then P(R)=∞ (for x>0). If P([n,n+1))=0, then P(R)=0. Takeaway: not all set functions can be calibrated to measure every subset (a kitchen scale cannot weigh a sheet of paper). Way out: restrict the domain to measurable sets. A possible domain here: F={∅,Ω,R−​,R+​}.

The argument, step by step.

  1. The intervals [n,n+1), n∈Z, are disjoint, there are countably many of them, and they cover R.
  2. They all have length 1, so "equal length means equal probability" forces P([n,n+1))=x for the same x.
  3. Axiom 3: 1=P(R)=∑n∈Z​x. This sum is 0 if x=0 and ∞ if x>0. It is never 1. Contradiction.

The proposed domain F={∅,R,R−​,R+​} (take R−​=(−∞,0) and R+​=[0,∞) so they are complements). On this small domain we can define a valid P, for example P(R−​)=P(R+​)=21​. The price: we can only ask "is the number negative?". Lecture 2 makes "a good domain" precise.

Part B: extra worked examples and problems

B1 (Bertsekas Problem 1.5). In a class, 60% are geniuses, 70% love chocolate, and 40% are both. Find the probability that a random student is neither.

Solution

Solution. Let G = genius and C = chocolate lover. "Neither" is Gc∩Cc=(G∪C)c by De Morgan. Then

P(G∪C)=0.6+0.7−0.4=0.9,P(neither)=1−0.9=0.1​.

B2 (Bertsekas Problem 1.6). A die is loaded so that each even face is twice as likely as each odd face; all even faces are equally likely, as are all odd faces. Build the model and find P(outcome<4).

Solution

Solution. Let each odd face have probability p, so each even face has 2p. Normalisation: 3p+3(2p)=1, so p=91​. Then

P({1,2,3})=p+2p+p=94​.

B3 (last year's HW 1, Sets Q1). Prove or disprove: if A∪B=A∪C and A∩B=A∩C, then B=C.

Solution

Solution. True. Take x∈B.

  • If x∈A, then x∈A∩B=A∩C, so x∈C.
  • If x∈/A, then x∈A∪B=A∪C, and since x∈/A, x∈C.

So B⊆C. By symmetry C⊆B, hence B=C. □ (Neither condition alone is enough: A={1}, B={1}, C=∅ satisfies the union condition but not B=C.)
