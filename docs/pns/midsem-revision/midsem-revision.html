Midsem Revision

Lectures 1 to 12

⏱ 12 min read

Short and crisp. Each block lists the must-know formulas, the traps, and a quick self-check. Built from the slides in Lectures/ (Lecture 1, 2, L3-1 … L12) and the M25 Midsem + Quiz 1 papers.

Practice map: HW1/Tut1 = counting · HW2/Tut2 = L1–L3 · HW3/Tut3 = L5–L6 · HW4/Tut4 = L7–L8 · HW5/Tut5 = L9–L12.

1. Probability spaces (Lectures 1, 2, start of L3)

  • Probability space (Ω, F, P). Ω = all outcomes, F = events you're allowed to measure, P = the measure.
  • σ-algebra F: contains ∅ and Ω; closed under complement; closed under countable union (so also countable intersection, via De Morgan).
  • Finite Ω → take F = 2^Ω (power set). Ω = ℝ → Borel σ-algebra B(ℝ), generated by intervals (a, b). It contains [a,b], [a,b), (−∞,b], {a}, …
  • Why not the power set of ℝ? You can't give every subset a probability consistent with the axioms (uniform-on-ℝ counterexample: each [n, n+1) gets x, and the total is then 0 or ∞).
  • Axioms: P(∅)=0, P(Ω)=1; countable additivity for disjoint events.
  • Consequences: P(Aᶜ)=1−P(A) · P(A∪B)=P(A)+P(B)−P(A∩B) · A⊆B ⇒ P(A)≤P(B) · Union bound P(∪Bᵢ) ≤ ΣP(Bᵢ).
  • Inclusion-exclusion (3 sets): P(A∪B∪C) = ΣP(A) − ΣP(A∩B) + P(A∩B∩C).
  • Continuity of P: Aₙ↑A or Aₙ↓A ⇒ P(Aₙ) → P(A). (Proof: write Fₙ = Aₙ − Aₙ₋₁, which are disjoint, and use countable additivity.)

Traps

  • Zero probability ≠ impossible. In U[0,1], P({0.5}) = 0, yet 0.5 can happen. Only ∅ is impossible.
  • Ω = ∪{ω} over an uncountable set, so you can't add up the P({ω}) = 0's: additivity is countable only.
  • To check whether a collection is a σ-algebra, test complements and unions of the sets you've added. Adding one set usually forces more.

Self-check: Why is F = {∅, [0,1], [0,.5), [.5,1], [.25,.75]} not a σ-algebra? (Its complement [0,.25)∪(.75,1] is missing.)

2. Conditioning, Bayes, independence, counting (L3)

  • Conditional: P(B|A) = P(A∩B)/P(A), for P(A) > 0. Equally likely outcomes: P(B|A) = |A∩B|/|A|.
  • Chain rule: P(A₁∩…∩Aₙ) = P(A₁)P(A₂|A₁)P(A₃|A₁A₂)…
  • Total probability: P(A) = Σ P(A|Bᵢ)P(Bᵢ), where {Bᵢ} partitions Ω.
  • Bayes: P(Bⱼ|A) = P(A|Bⱼ)P(Bⱼ) / Σᵢ P(A|Bᵢ)P(Bᵢ).
  • Independent: P(A∩B) = P(A)P(B). Then Aᶜ, B and Aᶜ, Bᶜ are independent too. For independent Aᵢ: P(∪Aᵢ) = 1 − Π(1 − P(Aᵢ)).
  • Mutual vs pairwise: mutual means every sub-collection factorises. Mutual ⇒ pairwise, but not the other way. Example: two fair tosses, A = 1st is H, B = 2nd is H, C = both tosses match. Each pair is independent, yet P(A∩B∩C) = 1/4 ≠ 1/8.
  • Correlation of events: positive if P(A|B) > P(A). A, B have the same sign as Aᶜ, Bᶜ, and the opposite sign to A, Bᶜ.
  • Conditional independence given C: P(AB|C) = P(A|C)P(B|C).

Traps

  • Mutually exclusive ≠ independent. If both have positive probability, disjoint events are dependent (P(A|B) = 0 ≠ P(A)).
  • A zero-probability event is independent of every event.
  • Conditional independence doesn't imply independence. Fair coin + two-headed coin example: given the coin, the tosses are independent, but P(A∩B) = 5/8 ≠ (3/4)².
  • Base-rate trap (robot example): 98% detection, 1% false alarm, 0.1% defective ⇒ P(defective | flagged) = 0.00098/(0.00098 + 0.00999) ≈ 0.089.

  • Multinomial: n!/(n₁!n₂!…n_r!) arrangements (e.g. PEPPER = 6!/(3!2!1!)), which is also the number of ways to split n items into groups of sizes nᵢ.
  • Stars and bars: n identical balls into r bins. No bin empty: C(n−1, r−1). Bins may be empty: C(n+r−1, r−1).
  • k heads in n tosses: C(n,k)pᵏ(1−p)ⁿ⁻ᵏ. First head on toss r: (1−p)^(r−1)p.

Self-check: Pick a number from {1,…,10}. A = less than 7, B = less than 8, C = even. Which pair is independent? (A and C: P(A∩C) = 0.3 = 0.6 × 0.5.)

3. Random variables, PMF, discrete distributions (L4, L5, L6)

  • RV: a map X: Ω → ℝ that is measurable, meaning X⁻¹(B) ∈ F for every Borel B. Induced measure: P_X(B) = P(X⁻¹(B)).
  • P, P_X, F_X relationship (asked in Quiz 1): F_X(x) = P_X((−∞, x]) = P({ω : X(ω) ≤ x}).
  • PMF: p_X(x) = P(X = x), with Σ p_X = 1. CDF: F_X(x) = Σ_{t≤x} p_X(t).
  • Expectation: E[X] = Σ x p_X(x). LOTUS: E[g(X)] = Σ g(x) p_X(x). You don't need the PMF of g(X).
  • PMF of Y = g(X): p_Y(y) = Σ_{x : g(x)=y} p_X(x). (Example: Y = |X| with X uniform on −4..4 gives p_Y(2) = 2/9.)
  • Linearity: E[aX+b] = aE[X]+b. Variance: Var(X) = E[(X−μ)²] = E[X²] − (E[X])². Var(aX+b) = a²Var(X).

  • Indicator 1_A: E[1_A] = P(A), and every moment equals P(A).
  • Geometric is memoryless: P(N > k) = (1−p)ᵏ, so P(N > k+m | N > k) = P(N > m).
  • Poisson is the limit of Binomial as n → ∞, p → 0 with np → λ.

Traps: "+b" shifts the mean but not the variance. Variance scales by a², not a. Check whether a Geometric counts trials (k ≥ 1) or failures (k ≥ 0).

Self-check (Quiz 1 Q2): derive E[X] and E[X²] for a Binomial. Hint: X = sum of n Bernoullis, so E[X²] = Var + mean² = np(1−p) + n²p².

4. Continuous RVs, standard pdfs, functions of RVs (L7, L8, start of L9)

  • CDF properties: non-decreasing, right-continuous (F(x) = F(x+)), F(−∞) = 0, F(∞) = 1. Right-continuity follows from continuity of P with Aₙ ↓ A. You can't get left-continuity because Aₙ ↑ {X < x}, not {X ≤ x}.
  • pdf: f = F′ and F(x) = ∫_{−∞}^x f. P(a ≤ X ≤ b) = ∫ₐᵇ f, and the endpoints don't matter, since P(X = a) = 0.
  • E[X] = ∫x f(x)dx, E[g(X)] = ∫g(x) f(x)dx.

  • Exp: E[Xⁿ] = n!/λⁿ. Memoryless: P(X > a+h | X > a) = e^(−λh) = P(X > h).
  • Normal: ∫e^(−x²/2)dx = √(2π) and Φ(−x) = 1 − Φ(x). aX + b is again normal, N(aμ+b, a²σ²) (Midsem Q5).
  • Linear map: f_Y(y) = (1/|a|) f_X((y−b)/a).
  • Monotone g, inverse h: f_Y(y) = f_X(h(y)) · |h′(y)|.
  • Non-monotone, e.g. Y = X²: go through the CDF. F_Y(y) = F_X(√y) − F_X(−√y), so f_Y(y) = [f_X(√y) + f_X(−√y)] / (2√y) for y > 0.

Recipe that always works: write F_Y(y) = P(g(X) ≤ y), turn it into an event about X, then differentiate. Write down the range of Y first.

Traps: for decreasing g, the event flips: {g(X) ≤ y} = {X ≥ h(y)}. Forgetting the |·| on h′. Forgetting that the pdf is 0 outside the range.

Self-check (Quiz 1 Q1): X ~ U[a,b], Y = e^(2X). Answer: F_Y(y) = (½ ln y − a)/(b−a) and f_Y(y) = 1/(2y(b−a)) on [e^(2a), e^(2b)].

5. Mixed RVs, joint distributions, independence, covariance (L9, L10)

  • Mixed RV: the CDF has continuous parts and jumps. E[Y] = ∫ y c(y) dy + Σ yₖ P(Y = yₖ), where c is the density of the continuous part. Example: X ~ U[0,1], Y = min(X, 0.5). Then F_Y(y) = y on [0, 0.5), with a jump of 0.5 at y = 0.5, and E[Y] = 0.125 + 0.25 = 0.375.
  • Joint: p_XY(x,y) or f_XY(x,y), with F_XY(x,y) = P(X ≤ x, Y ≤ y) and f_XY = ∂²F/∂x∂y.
  • Marginals: p_X(x) = Σ_y p_XY(x,y) and f_X(x) = ∫ f_XY(x,y) dy. Also F_XY(x, ∞) = F_X(x).
  • Independent RVs: joint = product of marginals (pmf/pdf and CDF). Then E[XY] = E[X]E[Y].
  • 2-D LOTUS: E[g(X,Y)] = ΣΣ g p_XY or ∬ g f_XY. E[aX+bY+c] = aE[X] + bE[Y] + c always, independent or not.
  • Covariance: Cov(X,Y) = E[XY] − E[X]E[Y]. Var(X+Y) = Var X + Var Y + 2Cov(X,Y) (Midsem Q4).
  • max/min of independent X, Y:
    • max: F_Z = F_X · F_Y
    • min: 1 − F_Z = (1 − F_X)(1 − F_Y)
    • min of independent Exp(λᵢ) is Exp(Σλᵢ) (Midsem Q3)

Traps

  • Uncorrelated ⇏ independent. Independence ⇒ Cov = 0, not the reverse.
  • Independence needs the factorisation to hold and a product-shaped (rectangular) support. f = c(x+y) on the unit square does not factorise, so X and Y are dependent (Midsem B(e)).
  • In a double integral the limits come from the support, so draw the region first.

Self-check: a die roll, X = 1 if odd, Y = 1 if even. Then E[XY] = 0 but E[X]E[Y] = 1/4, so they're dependent (and negatively correlated).

6. Conditioning on events and RVs, conditional expectation (L11, L12)

  • On an event A: p_{X|A}(x) = P({X=x} ∩ A)/P(A). If A = {X ∈ S}: p_X(x)/P(X ∈ S) for x ∈ S, and 0 otherwise.
  • E[X|A] = Σ x p_{X|A}(x), and LOTUS works conditionally too.
  • Total probability/expectation over a partition: p_X(x) = Σ P(Aᵢ) p_{X|Aᵢ}(x) and E[X] = Σ P(Aᵢ) E[X|Aᵢ].
  • On an RV: p_{X|Y}(x|y) = p_XY(x,y)/p_Y(y), so p_XY = p_{X|Y} p_Y. Continuous: f_{X|Y} = f_XY / f_Y.
  • E[X|Y=y] = Σ x p_{X|Y}(x|y), or ∫ x f_{X|Y}(x|y) dx.
  • E[X|Y] is a random variable: a function g(Y) of Y. Iterated expectation: E[E[X|Y]] = E[X].
  • Independent ⇒ p_{X|Y}(x|y) = p_X(x).
  • Geometric given N > n: p(k) = (1−p)^(k−1−n) p for k > n. That's memorylessness again.
  • Mixture: X ~ Exp(Y), with Y = λ₁ w.p. p and λ₂ w.p. 1−p ⇒ E[X] = p/λ₁ + (1−p)/λ₂.
  • Random sum Y = X₁ + … + X_N (iid, independent of N): E[Y] = E[N]E[X]. Also Var(Y) = E[N]Var(X) + (E[X])²Var(N) (the "section 4.5" HW).

Traps: E[X|Y=y] is a number, while E[X|Y] is a random variable. Write the conditional pdf's support in terms of y. Don't forget to divide by f_Y(y).

Self-check (Midsem Q1): roll a die until the first 6; each roll pays its face value, and the 6 pays 0. N ~ Geom(1/6), so E[N] = 6. Given N = n, the reward is 3(n−1). So E[reward] = 3(E[N] − 1) = 15.

Self-check (Midsem B): f = c(x+y) on [0,1]². c = 1, f_X(x) = x + ½, f_{X|Y}(x|y) = (x+y)/(y+½), E[X|Y=y] = (2+3y)/(3+6y). Not independent.

Midsem pattern (M25)

Section A: total expectation (die game), P(X<Y)=½ for iid U[0,1] (by symmetry, or ∫F_X(y)f_Y(y)dy), min of exponentials, Var(X+Y) proof, aX+b of a Gaussian. Section B: one joint-pdf problem covering constant → marginals → conditionals → E[X|Y=y] → independence. Quiz 1: Y=e^(2X) pdf/CDF, Binomial moments, definitions (RV, Borel σ-algebra, P vs P_X vs F_X), Exp mean + memoryless.

Expect derivations, not just numbers. Practise writing the CDF method and the proofs (Var(X+Y), E[E[X|Y]] = E[X], memoryless, right-continuity) cleanly.
