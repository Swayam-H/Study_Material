Part 7 — Worked practice problems

14 min read

These are from last year's HW 11, HW 12, Tutorial 11, Tutorial 12 and Endsem (the source is in brackets). Try each one before reading the solution: even just writing the likelihood or the posterior kernel yourself is most of the work.

A. Bias, MSE, consistency

Problem 1 [HW 11 Q1]

X1​,…,Xn​ i.i.d. with pdf fX​(x)=θ(x−21​)+1 on [0,1], θ∈[−2,2]. Estimator: Θ^n​=12Xˉ−6. Is it unbiased? Consistent? What's the MSE?

Solution. First, the moments of one X:

E[X]=∫01​x(θ(x−21​)+1)dx=θ(31​−41​)+21​=12θ​+21​.

So E[Θ^n​]=12(12θ​+21​)−6=θ. Unbiased.

For the variance:

E[X2]=θ(41​−61​)+31​=12θ​+31​,Var(X)=12θ​+31​−(12θ​+21​)2=121​−144θ2​.

Then

MSE(Θ^n​)=Var(12Xˉ)=n144Var(X)​=n12−θ2​.

This →0, so consistent (by the MSE theorem from slide 14).

Problem 2 [HW 11 Q3]

Xi​ i.i.d. with mean μ and variance σ2. Is μ^​B,n​=n1​∑i=1n​(1+i1​)Xi​ consistent?

Solution. Bias: E[μ^​B,n​]=nμ​∑(1+i1​)=μ(1+nHn​​), where Hn​=1+21​+⋯+n1​≈lnn. So B=μHn​/n→0 (since lnn/n→0).

Variance: Var=n2σ2​∑(1+i1​)2≤n2σ2​⋅4n=n4σ2​→0.

So MSE→0, and it's consistent (just biased for every finite n). The plain sample mean is consistent too, of course.

Problem 3 [Tutorial 11 Q5] (hard)

Xi​∼N(μ,σ2), both unknown, n≥2. (a) Show σ^ML2​ is biased. (b) Fix it. (c) Among estimators cσ^ML2​, which c minimises the MSE? (You may use: W=∑(Xi​−Xˉ)2 satisfies E[W]=(n−1)σ2 and Var(W)=2(n−1)σ4 for normal data.)

Solution. (a) σ^ML2​=W/n, so E=nn−1​σ2=σ2. (b) n−1n​σ^ML2​=W/(n−1) is unbiased.

(c) Write the estimator as aW (with a=c/n). Then

MSE(aW)=a2Var(W)+(aE[W]−σ2)2=σ4[2(n−1)a2+((n−1)a−1)2].

Differentiate in a and set to zero:

4(n−1)a+2(n−1)((n−1)a−1)=0⟹2a+(n−1)a=1⟹a=n+11​.

So the best estimator divides by n+1, i.e. c=n+1n​. Neither the MLE (n) nor the unbiased one (n−1) wins on MSE! Same lesson as the Uniform table: a bit of bias can buy a lot of variance reduction.

B. Maximum likelihood

Problem 4 [HW 11 Q2]

X1​,…,X4​ i.i.d. Geometric(p) with P(X=x)=p(1−p)x−1. Observed (2,3,3,5). Find the likelihood and the MLE.

Solution.

L(p)=∏p(1−p)xi​−1=p4(1−p)∑xi​−4=p4(1−p)9.

lnL=4lnp+9ln(1−p), so p4​=1−p9​, giving p^​=134​. In general, p^​=∑xi​n​=xˉ1​. (Mean of a geometric is 1/p, so this is the "invert the sample mean" pattern again.)

Problem 5 [Endsem Q5]

x1​,…,xn​ i.i.d. Uniform[a,b], both unknown. Find the MLEs.

Solution.

L(a,b)={(b−a)−n0​a≤minxi​ and b≥maxxi​otherwise.​

(b−a)−n gets bigger as the interval [a,b] gets shorter, but the interval must contain all the data. So make it as short as possible while still covering the data:

a^ML​=imin​xi​,b^ML​=imax​xi​.

(For full marks, say explicitly that ∂lnL/∂a=b−an​>0, so lnL increases in a up to the boundary minxi​, and similarly decreases in b down to maxxi​.)

Problem 6 [HW 11 Q10] (tricky)

Xi​ i.i.d. Uniform[θ,θ+1]. Find an MLE of θ. Is it unique? Unbiased? Consistent?

Solution. L(θ)=1 if every xi​∈[θ,θ+1], i.e. if

imax​xi​−1≤θ≤imin​xi​,

and 0 otherwise. So L is flat on a whole interval: every θ in [maxxi​−1,minxi​] is an MLE. The MLE is not unique.

Take θ^=mini​Xi​. The min of n Uniform[θ,θ+1] variables is θ+(min of n Uniform[0,1]), and E[min of n U[0,1]]=n+11​. So E[θ^]=θ+n+11​: biased, but asymptotically unbiased. And P(θ^−θ≥ϵ)=(1−ϵ)n→0, so it's consistent. (Picking maxXi​−1 gives bias −n+11​; the midpoint 2minXi​+maxXi​−1​ is unbiased by symmetry.)

Problem 7 [Tutorial 11 Q8] (subtle)

Xi​ i.i.d. Binomial(m,θ), m known, θ∈(0,1). (a) Find the MLE of θ. (b) Does the MLE of 1/θ exist?

Solution. (a) lnL=(∑xi​)lnθ+(nm−∑xi​)ln(1−θ)+C, so θ^=nm∑xi​​=mxˉ​.

(b) If all xi​=0 (which has positive probability), then L(θ)=(1−θ)nm, which increases as θ↓0. But θ=0 isn't in the parameter space (0,1), so the supremum is never attained: the MLE of θ doesn't exist for that data, and neither does the MLE of 1/θ. (Whenever ∑xi​>0, invariance gives 1/θ​=xˉm​.) The point: always check the maximiser lies in the allowed range.

Problem 8 [Endsem Q6]

Xi​ i.i.d. Poisson(γ). Find the MLE, its bias and MSE.

Solution. From slide 30, γ^​=Xˉ. Check the second derivative: −∑xi​/γ2<0 (if ∑xi​>0), so it's a max. E[Xˉ]=γ, so the bias is 0, and MSE=Var(Xˉ)=γ/n.

Problem 9 [HW 11 Q5]

One observation X∼N(0,σ2). (a) Find an unbiased estimator of σ2. (b) Write the log-likelihood. (c) Find the MLE of σ.

Solution. (a) E[X2]=Var(X)=σ2, so X2 is unbiased.

(b) lnL(σ)=−21​ln(2π)−lnσ−2σ2x2​.

(c) dσd​lnL=−σ1​+σ3x2​=0⟹σ^=∣x∣. (Not x: σ>0.)

C. Bayesian, MAP and CE

Problem 10 [Tutorial 12 Q1] — discrete prior

A coin is Type A (P(H)=0.25) or Type B (P(H)=0.75), each with prior 21​. You see HHT. Find P(A∣HHT) and the MAP estimate of P(H).

Solution.

P(HHT∣A)=0.252⋅0.75=643​,P(HHT∣B)=0.752⋅0.25=649​.

The priors are equal, so they cancel:

P(A∣HHT)=3/64+9/643/64​=41​.

MAP picks Type B, so p^​MAP​=0.75.

Problem 11 [Tutorial 12 Q2]

Prior p∼U[0,1]. One observation y=3 from Geometric(p). Find the full posterior, then the MAP and CE.

Solution. Posterior ∝p(1−p)2⋅1, which is the Beta(2,3) kernel. The normaliser is B(2,3)=4!1!2!​=121​, so

f(p∣y=3)=12p(1−p)2,0≤p≤1.

MAP: the Beta mode is 2+3−22−1​=31​. (Or differentiate: (1−p)2−2p(1−p)=0⇒p=31​.) This equals the MLE 1/y=31​, as it should with a flat prior.

CE: the Beta mean is 52​.

Problem 12 [Tutorial 12 Q3] — Gaussian, unequal variances

Rod length μ; one measurement x∼N(μ,1). Prior μ∼N(10,1). You measure x1​=12. Posterior?

Solution. Precisions add: σpost2​1​=11​+11​=2, so σpost2​=21​. Mean: 21​(110​+112​)=11.

μ∣x1​=12 ∼ N(11, 21​).

The prior and the single measurement are equally reliable, so the answer is halfway between them.

Problem 13 [Tutorial 12 Q4] — Gamma–Poisson with data

Cars per hour ∼ Poisson(λ), prior Gamma(2,1). Counts over 3 hours: 2,3,4. Find the posterior, MAP and CE.

Solution. ∑xi​=9, n=3, so the posterior is Gamma(2+9, 1+3)=Gamma(11,4).

λ^MAP​=411−1​=2.5,λ^CE​=411​=2.75.

Compare with the MLE xˉ=3: the prior (mean 2) pulls the estimate down a bit. Check via the weighted-average formula: 41​⋅2+43​⋅3=2.75. ✓

Problem 14 [Tutorial 12 Q6]

Prior fX​(x)=3x2 on [0,1], and Y∣X=x∼ Geometric(x). Find the MAP of X given Y=5.

Solution. Posterior ∝3x2⋅x(1−x)4∝x3(1−x)4 (a Beta(4,5) kernel). Maximise 3lnx+4ln(1−x):

x3​=1−x4​⟹x^MAP​=73​.

Problem 15 [HW 12 P1] — truncated prior

Bus waiting times are Exp(Θ). Prior: fΘ​(θ)=10θ on [0,1/5​]. (a) Alvin waits 30 min once. Find the posterior, MAP and CE. (b) Over five days he waits 30, 25, 15, 40, 20. Same questions.

Solution. (a) Posterior ∝10θ⋅θe−30θ∝θ2e−30θ on [0,1/5​], normalised by c=∫01/5​​θ2e−30θdθ.

MAP: dθd​(2lnθ−30θ)=θ2​−30=0⇒θ=151​. That's inside [0,0.447], so θ^MAP​=151​≈0.067.

CE: ∫01/5​​θ2e−30θdθ∫01/5​​θ3e−30θdθ​. Without the truncation, this would be the mean of a Gamma(3,30), i.e. 303​=0.1. The cut at 0.447 is far out in the tail (30×0.447≈13), so it barely matters: numerically θ^CE​≈0.0999.

(b) ∑xi​=130, n=5. Posterior ∝θ⋅θ5e−130θ=θ6e−130θ on the same range. MAP =1306​=653​≈0.046. CE ≈1307​≈0.054.

The lesson: a truncated prior just restricts the support. Find the unrestricted peak, and check that it lands inside the allowed range.

Problem 16 [HW 12 P3] (hard) — triangular prior

Θ has the triangular prior fΘ​(θ)=2−4​21​−θ​ on [0,1]. You see k heads in n tosses. Find the MAP.

Solution. The prior is 4θ on [0,21​] and 4(1−θ) on [21​,1]. So the posterior is, up to a constant,

g(θ)={θk+1(1−θ)n−kθk(1−θ)n−k+1​0≤θ≤21​21​≤θ≤1​

(It's continuous at 21​.) Each piece is a Beta-shaped bump:

  • the left piece peaks at n+1k+1​,
  • the right piece peaks at n+1k​.

Now three cases:

  1. If n+1k+1​≤21​ (i.e. k≤2n−1​), the left peak is inside its piece. The right piece is decreasing on [21​,1] (its peak n+1k​ is even further left). So θ^MAP​=n+1k+1​.
  2. If n+1k​≥21​ (i.e. k≥2n+1​), by symmetry θ^MAP​=n+1k​.
  3. Otherwise (k=2n​, n even), the left piece is increasing all the way to 21​ and the right piece is decreasing from 21​, so θ^MAP​=21​.

Intuition: compared with the MLE nk​, the prior nudges the estimate towards 21​.

Problem 17 [HW 12 P5] — MAP as a decision rule

Box 1 has 1 black, 2 white balls; box 2 has 2 black, 1 white. You pick box 1 with probability p, then draw one ball. (a) MAP rule? (b) With p=21​, probability of error, vs not drawing at all?

Solution. (a) Given black: compare p⋅31​ (box 1) vs (1−p)⋅32​ (box 2). Choose box 1 iff p>32​. Given white: compare p⋅32​ vs (1−p)⋅31​. Choose box 1 iff p>31​.

(b) With p=21​: black ⇒ box 2, white ⇒ box 1. Errors happen when you see black from box 1, or white from box 2:

P(error)=21​⋅31​+21​⋅31​=31​.

Without a draw, the best you can do is guess, with error 21​. One ball cuts your error from 21​ to 31​.

Problem 18 [HW 12 P7] — ML vs MAP for a signal

X∼N(0,σX2​) is sent, and you receive Y=aX+bW, with W∼N(0,σW2​) independent of X. Find the ML and MAP estimates of X given Y=y.

Solution. Given X=x, Y∼N(ax,b2σW2​).

ML: maximise −2b2σW2​(y−ax)2​, so x^ML​=ay​.

MAP: maximise −2b2σW2​(y−ax)2​−2σX2​x2​. Differentiate:

b2σW2​a(y−ax)​=σX2​x​⟹x^MAP​=a2σX2​+b2σW2​aσX2​​y.

Sanity checks: if the noise is tiny (σW​→0), MAP →y/a = ML. If the noise is huge, MAP →0, the prior mean: you stop trusting the measurement. This is the same shrinkage idea as ridge regression.

Problem 19 [HW 12 P8] — CE with a uniform prior

Θ∼U[4,10], and X=Θ+U with U∼U[−1,1] independent of Θ. Find E[Θ∣X=x].

Solution. fX∣Θ​(x∣θ)=21​ if ∣x−θ∣≤1. So the posterior is ∝61​⋅21​ (a constant) on

θ∈[4,10]∩[x−1,x+1],

i.e. the posterior is uniform on that overlap, and the CE is the midpoint:

E[Θ∣X=x]=⎩⎨⎧​2x+5​x2x+9​​3≤x≤5(overlap [4,x+1])5≤x≤9(overlap [x−1,x+1])9≤x≤11(overlap [x−1,10])​

Note the MAP isn't unique here: every point of the overlap is a peak.

Problem 20 [Endsem Q9]

x1​,…,xn​ i.i.d. Exp(λ), prior Gamma(α,β). Find the posterior and the MAP.

Solution. From Part 4: posterior Gamma(α+n, β+∑xi​). MAP = mode =β+∑xi​α+n−1​. (And for completeness, CE =β+∑xi​α+n​; as n→∞ both →xˉ1​=λ^ML​.)

For the exam, write the posterior derivation the long way like the official solution does (keep the normalising integral and evaluate it with the Gamma function), unless the question says "identify".
