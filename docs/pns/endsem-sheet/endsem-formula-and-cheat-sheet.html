SECTION 1 (5 marks each)

1. MGF

MX​(t)=E[etX]
E[Xk]=MX(k)​(0)
MaX+b​(t)=ebtMX​(at)
  • Independent: MX+Y​=MX​MY​; i.i.d. sum MSn​​=MXn​. M(0)=1 always (sanity check).
  • K=lnM: K′(0)=EX, K′′(0)=VarX (faster than differentiating M twice).
  • Random sum Z=∑i=1N​Xi​, N indep of the Xi​: MZ​(t)=MN​(lnMX​(t)), EZ=ENEX, VarZ=ENVarX+(EX)2VarN.
  • Mixture (choose Yi​ w.p. pi​): M=∑pi​MYi​​. Read off a pmf: M(t)=∑pk​etxk​⇒P(X=xk​)=pk​.
  • Uniqueness (equal MGFs near 0 ⇒ same law) and continuity (MXn​​→MX​ near 0 ⇒ Xn​d​X).
  • Closed sums: Bin+Bin (same p), Poi+Poi, Normal+Normal, n Exp(λ) = Gamma(n,λ), Gamma+Gamma (same λ). Geom(p) many Exp(λ) = Exp(pλ); Poi(λ) many Bern(p) = Poi(λp).

Move: "find the distribution of a sum / transform" = multiply MGFs, match the table. "Find moments" = differentiate at 0 (or expand as a power series and read E[Xk]/k!). Traps: product rule needs independence. Say where M is finite (Exp: t<λ). Cauchy has no MGF.

2. Tower rule (iterated expectation)

E[X]=E[E[X∣Y]]
Var(X)=E[Var(X∣Y)]+Var(E[X∣Y])
  • E[X∣Y] is a random variable, a function g(Y) where g(y)=E[X∣Y=y].
  • Pull out what is known: E[h(Y)X∣Y]=h(Y)E[X∣Y]. So E[XY]=E[YE[X∣Y]].
  • Independent: E[X∣Y]=EX. Always E[(X−E[X∣Y])h(Y)]=0.
  • E[X∣Y] minimises E[(X−g(Y))2] over all g (the MMSE / CE estimator).
  • Discrete version: EX=∑y​E[X∣Y=y]P(Y=y); continuous: ∫E[X∣Y=y]fY​(y)dy.

Move: when X depends on a random parameter (stick broken at a uniform point, coin with random bias p∼U, Poisson with random rate), condition on the parameter, compute the inner mean/variance as a formula in it, then average. Classic: stick of length ℓ, break at Y∼U[0,ℓ], then X∼U[0,Y]: EX=4ℓ​. Coin P∼U[0,1], n tosses: E[#H]=2n​, P(#H=k)=n+11​. Traps: VarX=E[Var(X∣Y)]; the second term is easy to forget.

3. Conditioning (events, Bayes)

P(A∣B)=P(B)P(A∩B)​
P(A)=i∑​P(A∣Bi​)P(Bi​)
P(Bj​∣A)=∑i​P(A∣Bi​)P(Bi​)P(A∣Bj​)P(Bj​)​
  • Chain rule: P(A1​⋯An​)=P(A1​)P(A2​∣A1​)⋯. Independence: P(AB)=P(A)P(B); mutual ≠ pairwise.
  • RV given an event A: fX∣A​(x)=P(X∈A)fX​(x)​ for x∈A, 0 elsewhere. E[X∣A]=∫xfX∣A​.
  • Total expectation: EX=∑i​E[X∣Ai​]P(Ai​). Use it for "first step" problems (e.g. E[tosses until HH]=6).
  • Geometric/Exp memorylessness: X−s∣X>s has the original law.

Move: tree diagram, write the partition, then Bayes. For mixed problems (discrete cause, continuous effect): P(B∣X=x)=∑fX∣Bi​​(x)P(Bi​)fX∣B​(x)P(B)​. Traps: P(A∣B)=P(B∣A) (base-rate). Conditioning on a zero-probability event needs densities.

4. Marginalization and conditioning (joint distributions)

fX​(x)=∫fX,Y​(x,y)dy
fX∣Y​(x∣y)=fY​(y)fX,Y​(x,y)​
fX,Y​=fY​fX∣Y​
  • Normalise first: ∬f=1 gives the constant.
  • Draw the support. Limits of ∫dy depend on x (e.g. 0<y<x<1: fX​(x)=∫0x​fdy, fY​(y)=∫y1​fdx).
  • P((X,Y)∈A)=∬A​f. E[g(X,Y)]=∬gf.
  • Independent ⇔ fX,Y​=fX​fY​, i.e. factorises and the support is a rectangle. 0<y<x<1 is never independent.
  • Conditional pdf in x for fixed y is a normalised slice of fX,Y​; read its family off the shape (e.g. uniform slice).
  • Discrete: pX​(x)=∑y​pX,Y​(x,y); table row/column sums.
  • Continuous Bayes: fX∣Y​(x∣y)=∫fY∣X​(y∣x′)fX​(x′)dx′fY∣X​(y∣x)fX​(x)​.

Move: sketch region → constant → marginals with x-dependent limits → conditional = joint/marginal with the support stated → E[X∣Y=y]. Traps: forgetting the support/indicator in the answer; marginal limits taken as constants on a triangular region; uncorrelated ≠ independent.

6. Monte Carlo

θ=∫ab​h(x)dx=(b−a)E[h(U)]
θ^N​=Nb−a​i=1∑N​h(Ui​)
  • Unbiased; Varθ^N​=N(b−a)2σh2​​; consistent by SLLN; CI by CLT: θ^±1.96N​σ^​. Error ∝N​1​.
  • Sample size for error ≤ϵ w.p. 1−δ: Chebyshev N≥ϵ2δσ2​; CLT N≥(ϵzσ​)2.
  • Probability p=P(A): p^​ = fraction of hits, Var=Np(1−p)​≤4N1​. π: P(U12​+U22​≤1)=4π​, so π^=4p^​.
  • Infinite range: ∫0∞​h=E[h(X)/f(X)] for any density f>0 there, e.g. X∼Exp(1): E[h(X)eX]. Or substitute y=1+x1​.
  • Multiple integrals over [0,1]d: same, average h(U1​,…,Ud​).
  • Importance sampling: Ef​[h(X)]=Eg​[h(Y)g(Y)f(Y)​], need g>0 where hf=0; best g∝∣h∣f.

Move: rewrite the integral as an expectation, name the estimator, show E=θ, compute its variance, then Chebyshev/CLT for N. Traps: forgetting the (b−a) factor; the variance is of h(U), not of U.

7. Random vector

CX​=E[(X−μ)(X−μ)T]=E[XXT]−μμT
E[AX+b]=Aμ+b
CAX+b​=ACX​AT
  • C symmetric PSD: aTCa=Var(aTX)≥0. Singular ⇔ some aTX is constant. Cov(aTX,bTX)=aTCb.
  • Jacobian: Y=G(X), inverse H: fY​(y)=fX​(H(y))∣det∂y∂H​∣,  ∣det∂y∂H​∣=1/∣det∂x∂G​∣. Affine: ∣detA∣1​fX​(A−1(y−b)). Polar: extra factor r. (X1​+X2​,X1​−X2​): ∣J∣=21​.
  • One function only (e.g. X1​/X2​): add a dummy Y2​=X2​, transform, integrate y2​ out.
  • Gaussian vector N(μ,Σ): f=(2π)n/2detΣ​1​e−21​(x−μ)TΣ−1(x−μ). AX+b∼N(Aμ+b,AΣAT); every aTX is normal; marginals = sub-blocks; uncorrelated ⇒ independent (jointly Gaussian only).
  • Generate N(μ,Σ): X=AZ+μ, AAT=Σ. 2×2 Cholesky A=[σ1​ρσ2​​0σ2​1−ρ2​​]. Box–Muller: −2lnU1​​(cos,sin)(2πU2​).
  • 2×2: det=ad−bc, inverse ad−bc1​[d−c​−ba​].

Traps: ACAT not ATCA; shift b drops out of C; state the new support after a Jacobian; Y=±X (fair coin) is normal, uncorrelated with X, yet dependent.

8. Probabilistic inequalities

Markov: P(X≥a)≤aEX​ (X≥0)
Chebyshev: P(∣X−μ∣≥c)≤c2σ2​
  • Generalised Markov: P(∣X∣≥a)≤arE∣X∣r​; Chebyshev = Markov on (X−μ)2.
  • Chernoff (Markov on etX): P(X≥a)≤mint>0​e−taMX​(t).
  • Union bound: P(∪Ai​)≤∑P(Ai​). Jensen: g convex ⇒ g(EX)≤E[g(X)] (so (EX)2≤EX2, E[1/X]≥1/EX for X>0, EX​≤EX​). Cauchy–Schwarz: (E[XY])2≤E[X2]E[Y2].
  • Proof of Markov (often asked): a1{X≥a}≤X, take expectations.
  • Chebyshev on the sample mean: P(∣Mn​−μ∣≥ϵ)≤nϵ2σ2​. Polling ±0.01 at 95%: n≥4ϵ2δ1​=50,000 (CLT gives 9604).
  • Within k sd: P(∣X−μ∣<kσ)≥1−k21​.

Move: compute the exact probability too when asked to compare, and comment that the bound is loose but distribution-free. Traps: Markov needs X≥0; a bound >1 is useless but not wrong.

9. SLLN and CLT

Xi​ i.i.d., mean μ, variance σ2<∞, Mn​=nSn​​: EMn​=μ, VarMn​=nσ2​.

  • WLLN: Mn​p​μ (proof: Chebyshev above). SLLN: P(limMn​=μ)=1 (needs only E∣X∣<∞). Fails for Cauchy.
  • CLT:
Zn​=σn​Sn​−nμ​d​N(0,1)
Sn​≈N(nμ,nσ2),Mn​≈N(μ,nσ2​)
  • Continuity correction (integer Sn​): P(Sn​≤k)≈Φ(σn​k+0.5−nμ​), P(Sn​≥k)≈1−Φ(σn​k−0.5−nμ​), P(Sn​=k) with k±0.5.
  • Bin(n,p)≈N(np,np(1−p)); Poi(λ)≈N(λ,λ); Gamma(n,λ)≈N(λn​,λ2n​).
  • SLLN uses: Monte Carlo is consistent, the empirical frequency →p, n1​∑g(Xi​)→Eg(X) a.s., n1​∑Xi2​→EX2.

Move: write the quantity as a sum of i.i.d. terms, find one term's μ,σ2, standardise, apply correction if integer, read Φ. Traps: σn​ for the sum, σ/n​ for the mean; the CLT is about distribution, it says nothing a.s.

10. MSE and MLE (estimation)
